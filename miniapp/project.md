## 产品概要

面向非专业编程用户的碎片化学习工具，通过知识卡片、刷题练习与间隔重复记忆强化，帮助 AI 编程学习者建立计算机基础认知，使其更高效地驾驭 AI 工具完成软件开发任务。

**核心闭环**：知识卡片（输入） → 刷题 + 记忆强化（巩固） → AI 编程实践（输出），积分体系贯穿全程。

详细产品定义参见 [PRD.md](docs/PRD.md)。

## 核心功能模块

根据 PRD §2，v1.0 包含五大核心模块：

| 模块 | 核心功能点 | 关键业务规则 | PRD 章节 |
|------|-----------|-------------|:------:|
| **笔记管理** | 自由笔记 / 关联笔记；三级审核流程（敏感词→AI审查→人工复核）；审核通过后可分享 | 本地存储默认不上传；首次进入风险告知；单用户上限500条；累计3次违规限制提审7天；连续3次驳回冻结分享7天 | §2.1 |
| **知识学习** | 七大知识领域（K01~K07），知识卡片浏览 + 刷题练习（单选），错题本自动收集 | K01~K03 免费；K04~K07 需积分解锁（30~60积分/领域）；每日挑战3~5题全对方可获得积分 | §2.2 |
| **记忆强化** | 基于艾宾浩斯遗忘曲线的间隔复习、错题再练、笔记回顾、遗忘预警；用户可自定义复习计划 | 默认复习节点 [1,2,4,7,15]天；每日复习上限20张；遗忘预警默认7天；复习提醒默认20:00 | §2.3 |
| **学习积分制** | 学习行为 + 激励广告观看获取积分，积分解锁高级知识领域（K04~K07）和虚拟成就徽章 | 积分不可转赠/不可提现/永久有效；卸载后数据丢失（v1.0无云端同步）；详见积分体系表 | §2.4 |
| **首页个性化** | Banner 轮播（运营推送）、主题色管理端动态下发、首页模块显隐与拖拽排序 | Banner 750×300px，最多5张，3秒自动轮播；主题色客户端实时生效无需重启；兜底策略无Banner自动隐藏 | §2.5 |

## 知识内容体系

PRD §2.2.1 定义七大知识领域，以「章-节-知识点」三级结构组织：

| 编号 | 知识领域 | 卡片预估 |
|:----:|---------|:------:|
| K01 | 编程基础概念 | 10~15 |
| K02 | 计算机网络基础 | 8~12 |
| K03 | 软件工程流程 | 8~10 |
| K04 | 数据库基础 | 6~10 |
| K05 | 操作系统基础 | 5~8 |
| K06 | AI编程实践技巧 | 8~12 |
| K07 | AI编程与传统编程 | 10~14 |

> K01~K03 免费开放；K04~K07 需消耗积分解锁（30~60 积分/领域）。

## 盈利模式

PRD §3 定义：开屏广告（冷启动可跳过）+ 激励广告（用户自愿观看获取积分）。积分→解锁知识→学习更多→积分稀缺→广告成为稳定收入来源，形成盈利闭环。

## 核心原则：纯前端项目

这是一个**纯粹的前端项目**（微信小程序），不包含后端服务。

### 后端调用规范

在遇到需要调用后端接口的场景时：
1. **严格依照后端 SDK 文档**进行调用
2. 如果发现后端 SDK 文档与后端实际提供的 SDK **不一致**：
   - **坚持以文档为准**
   - **不得**直接使用后端 SDK 中提供的不符合规范的 SDK
   - 将问题原因报告为**后端问题**，由后端团队修正
3. **不要**强行改变前端业务逻辑来适配后端的错误实现

### 设计还原规范

1. 所有 UI 实现严格参照交互设计文档中的设计规范
2. 设计 Token（颜色、圆角、阴影、字体）以交互设计文档定义值为准
3. Pixso 设计稿为视觉还原的最高参照标准
4. 主题色支持管理端动态下发（参见 PRD §2.5.3），默认品牌主色为 #4A90D9（科技蓝）
