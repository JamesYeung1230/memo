# 卡片学记 — 知识卡片学习小程序

基于**知识卡片 + 选择题测验**的微信小程序，通过"先学习、后测验、再重复"的学习闭环，帮助用户高效记忆和理解知识。

## 技术栈

- **框架**：微信原生框架
- **渲染引擎**：Skyline
- **组件框架**：glass-easel
- **设计来源**：Pixso
