## 1. 产品概述

### 1.1 产品背景

传统的学习工具存在以下痛点：
- **被动学习**：用户只是阅读材料，缺乏主动回忆机制
- **遗忘曲线**：学过的内容随时间快速遗忘，缺少科学复习提醒
- **枯燥乏味**：纯文本阅读缺乏互动性，难以坚持
- **反馈缺失**：学习过程中无法即时验证理解程度

### 1.2 产品定位

一款基于**知识卡片 + 选择题测验**的学习工具小程序，通过"先学习、后测验、再重复"的闭环设计，利用**主动回忆 (Active Recall)** 和**间隔重复 (Spaced Repetition)** 两大认知科学原理，帮助用户高效记忆和理解知识。

### 1.3 产品口号

> **"每日一卡，积少成多"**

### 1.4 目标用户

| 用户画像 | 描述 |
|---------|------|
| **学生群体** | 考研、考公、考证、期中期末复习的学生 |
| **职场学习者** | 需要学习新知识、准备面试、提升技能的职场人 |
| **终身学习者** | 日常有碎片化阅读和学习习惯的用户 |
| **知识创作者** | 希望将自己的知识整理成卡片分享给他人的用户 |

## 3. 功能详细需求

### 3.1 知识卡片学习

#### 3.1.1 卡片模型

每张知识卡片包含以下信息：

| 字段 | 类型 | 说明 |
|------|------|------|
| 正面内容 | 富文本 | 知识点标题 / 问题 / 概念 |
| 背面内容 | 富文本 | 详细解释 / 答案 / 补充 |
| 分类 / 主题 | 标签 | 所属知识分类 |
| 来源 | 文本 | 用户创建或导入 |
| 创建时间 | 时间戳 | - |
| 学习次数 | 整数 | 累计学习次数 |
| 最后学习时间 | 时间戳 | - |
| 掌握度 | 0-100% | 根据答题正确率自动计算 |
| 标签 | 数组 | 自定义标签，用于多维度分类 |

#### 3.1.2 卡片学习交互

1. **列表浏览**：以卡片列表形式展示当前分类下的卡片
2. **翻转交互**：
   - 点击卡片 → 3D 翻转动画，展示背面内容
   - 再次点击 → 翻转回正面
3. **学习模式**：
   - **浏览模式**：快速翻阅卡片，无测验
   - **学习模式**：看卡片 → 做选择题 → 标记"记住了" / "需复习"

#### 3.1.3 学习算法

基于**简化版间隔重复**算法：

| 学习阶段 | 行为 | 下次复习间隔 |
|----------|------|-------------|
| 第1次学习 | 首次学习卡片并答题正确 | 1天 |
| 第2次复习 | 答题正确 | 3天 |
| 第3次复习 | 答题正确 | 7天 |
| 第4次复习 | 答题正确 | 14天 |
| 任意阶段 | 答题错误 | 重置为1天后再复习 |

### 3.2 选择题测验

#### 3.2.1 出题逻辑

- 每张知识卡片自动生成**1道选择题**（4个选项）
- 卡片正面内容作为**题干**
- 卡片背面内容作为**正确答案**
- AI / 模板生成 3 个**干扰选项**
- 支持**手动编辑题目和选项**

#### 3.2.2 答题流程

```
进入测验 → 展示题干 → 用户选择答案
    ↓
选择正确 ← 展示✓动画 + 解析
    ↓
选择错误 ← 展示✗动画 + 正确答案 + 解析
    ↓
进入下一题 / 查看结果统计
```

#### 3.2.3 答题反馈设计

| 状态 | 视觉反馈 | 交互反馈 |
|------|---------|---------|
| 选择正确 | 选项高亮绿色 + ✓ 图标 | 轻微震动反馈 |
| 选择错误 | 选项高亮红色 + ✗ 图标 + 正确选项绿色 | 震动反馈 + 抖动画 |
| 查看解析 | 底部弹出解析面板 | 拖拽收起 |
| 答题完成 | 庆祝动画 + 统计卡片 | 分数 + 用时 + 建议 |

### 3.3 知识库管理

#### 3.3.1 创建知识卡片

- 支持**手动输入**创建
- 支持**拍照识别文字**（OCR，后期版本）
- 支持**从文本导入**批量创建
- 自动提取标题和内容分隔

#### 3.3.2 分类管理

- 用户可创建**多层分类**（如：英语 > 词汇 > 四级）
- 卡片可归属于**多个标签**
- 提供**默认分类**（未分类）

### 3.4 学习统计

| 指标 | 展示方式 | 说明 |
|------|---------|------|
| 今日学习卡片数 | 数字卡片 | 当日学习量 |
| 连续打卡天数 | 日历视图 | 学习习惯 |
| 累计学习卡片数 | 进度条 | 总进度 |
| 本周正确率 | 折线图 | 正确率趋势 |
| 各分类掌握度 | 雷达图 | 分类能力分布 |
| 待复习卡片数 | 徽标提醒 | 及时复习 |

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 目标 |
|------|------|
| 页面首屏加载 | ≤ 1.5s |
| 卡片翻转动画 | 60fps，无卡顿 |
| 知识包导入（100张） | ≤ 2s |
| 数据查询 | ≤ 500ms |

### 5.2 安全要求

- 数据存储在**本地存储**为主，用户隐私数据不上传
- 云同步需用户**主动授权**
- 反对任何形式的用户数据采集与滥用

### 5.3 兼容性

- 支持 iOS 微信 8.0+ 和 Android 微信 8.0+
- 支持微信小程序基础库 3.0.0+
- 适配全面屏、刘海屏、折叠屏

### 5.4 视觉设计规范

设计规范基于 **Pixso 设计稿**（组件：封面/组合1）提取的品牌设计语言。

| Token 名称 | 值 | 说明 |
|-----------|-----|------|
| **主色调** | `#160C57`（深紫色） | 品牌色，用于导航栏、按钮、重点元素 |
| 主色透明 | `rgba(22, 12, 87, 0.3)` | 描边、轻量装饰 |
| 辅助色 | `#082706`（深绿色） | 阴影色 |
| 卡片圆角 | **30px** | 统一大圆角风格 |
| 卡片描边 | **8px** 深紫描边 | 品牌识别边框 |
| 卡片阴影 | Y:20px / Blur:40px / 30%深绿 | 立体层次感 |
| 成功色 | `#52C41A` | 正确反馈 |
| 错误色 | `#FF4D4F` | 错误反馈 |
| 背景色 | `#F5F7FA` | 页面底色 |

详细设计 Token 请参见 [交互设计文档](交互设计.md) 第 6 章。

### 5.5 可用性

- 支持**离线使用**（本地存储）
- 核心功能（浏览卡片、答题）无需网络
- 云同步仅在有网络时自动进行

## 6. 用户旅程

### 6.1 新用户首次使用

```
首次打开 → 引导页（3步操作指引）
    ↓
创建第一个分类（如："考研英语"）
    ↓
手动创建第1张知识卡片
    ↓
进入学习模式 → 浏览卡片 → 回答问题
    ↓
查看学习统计 → 完成首次学习
```

### 6.2 日常使用流程

```
打开小程序 → 首页（今日待复习卡片）
    ↓
查看第1张卡片 → 正面展示 → 尝试回忆
    ↓
点击翻转 → 查看答案 → 点击"记住了"
    ↓
进入选择题 → 回答问题 → 即时反馈
    ↓
继续下一张 / 查看今日统计
    ↓
完成学习 → 打卡
```
