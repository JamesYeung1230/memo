## 1. 页面结构

### 1.1 全局导航

采用 **Tab Bar 底部分栏导航** 结构，共 3 个主 Tab：

```
┌──────────────────────────────────┐
│                                  │  ← 自定义导航栏（分类名称 + 搜索）
│                                  │
│          页面内容区域              │
│                                  │
│                                  │
├──────────────────────────────────┤
│  🏠 学习  │  📚 知识库  │  👤 我的  │  ← Tab Bar
└──────────────────────────────────┘
```

| Tab | 页面 | 核心功能 |
|-----|------|---------|
| 学习 | 首页 | 今日待复习、快速开始学习 |
| 知识库 | 知识库首页 | 分类浏览、卡片管理 |
| 我的 | 个人中心 | 统计、设置、数据管理 |

### 1.2 页面拓扑

```
Tab: 学习
├── 首页 (学习首页)
│    ├── 今日待复习卡片列表
│    ├── 快速学习入口
│    └── 学习日历/打卡入口
├── 学习模式 → 卡片浏览 → 翻转交互
├── 测验模式 → 选择题作答 → 结果页
└── 学习完成页 → 统计摘要

Tab: 知识库
├── 知识库首页
│    ├── 分类列表（网格/列表视图）
│    └── 搜索入口
├── 分类详情 → 卡片列表
├── 卡片详情 → 翻转查看
└── 创建卡片 / 创建分类

Tab: 我的
├── 个人中心
│    ├── 学习统计（今日、累计、连续）
│    ├── 错题本入口
│    ├── 收藏卡片入口
│    └── 设置入口
├── 学习统计详情页
├── 错题本
├── 收藏夹
└── 设置页

独立页面:
├── 引导页（首次使用）
├── 创建卡片页（模态弹出）
├── 编辑题目页（模态弹出）
└── 导入/导出页
```

```
│  │                          │   │

│  │    点击翻转查看答案        │   │
│  └──────────────────────────┘   │
│                                  │
│  ┌──────┐  ┌──────┐  ┌──────┐  │

│  └──────┘  └──────┘  └──────┘  │
├──────────────────────────────────┤
│         继续答题 →                │  ← 进入测验按钮
└──────────────────────────────────┘
```

#### 2.2.2 翻转交互

```
点击卡片时：
┌──────────────────────┐     ┌──────────────────────┐
│                      │     │                      │
│  TCP 三次握手的       │     │  1. SYN  ────→       │
│  过程是？             │  →  │  2. SYN+ACK ←───     │
│                      │     │  3. ACK  ────→       │
│                      │     │                      │
│  点击翻转查看答案      │     │  客户端发送SYN，服务    │
│                      │     │  端回复SYN+ACK...     │
└──────────────────────┘     └──────────────────────┘
    正面（问题）                  背面（答案）
```

**翻转动画参数**：

| 参数 | 值 |
|------|-----|
| 动画类型 | 3D Y 轴旋转 (rotateY) |
| 持续时间 | 400ms |
| 缓动函数 | ease-in-out |
| 背面可见性 | backface-visibility: hidden |

#### 2.2.3 交互说明

| 元素 | 交互 | 反馈 |
|------|------|------|
| 卡片主体 | 点击 → 3D 翻转 | 平滑翻转动画 |
| 卡片主体（背面） | 点击 → 翻转回正面 | 反向翻转动画 |
| "忘了" 按钮 | 点击标记 → 该卡片进入错题本 | 按钮变为红色 + 左滑消失动画 |
| "犹豫" 按钮 | 点击标记 → 复习间隔不变 | 按钮变为黄色 |
| "记住" 按钮 | 点击标记 → 延长复习间隔 | 按钮变为绿色 + 右滑消失动画 |
| "继续答题" | 点击进入**测验模式** | 底部 sheet 弹出 |
| 进度指示 | 顶部 (3/12) 实时更新 | 数字 + 进度条更新 |
| 右滑卡片 | 返回上一张卡片 | 跟随手指的滑动动画 |
| 左滑卡片 | 跳过当前卡片（不标记） | 卡片淡出 |

### 2.3 测验模式

#### 2.3.1 页面布局

```
┌──────────────────────────────────┐
│  ← 退出   选择题   3/12    📊    │  ← 导航栏（进度 + 结果按钮）
├──────────────────────────────────┤
│                                  │
│  根据刚才学习的卡片，回答以下问题   │
│                                  │
│  ┌──────────────────────────┐   │
│  │                          │   │
│  │  TCP 三次握手中，第二     │   │
│  │  步的报文类型是？          │   │  ← 题干
│  │                          │   │
│  └──────────────────────────┘   │
│                                  │
│  ┌──────────────────────────┐   │
│  │  A. SYN                   │   │  ← 选项（正常状态）
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │  B. SYN+ACK               │   │
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │  C. ACK                   │   │
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │  D. FIN                   │   │
│  └──────────────────────────┘   │
│                                  │
│  ┌──────────────────────────┐   │
│  │      确认选择               │   │  ← 提交按钮（选中后亮起）
│  └──────────────────────────┘   │
├──────────────────────────────────┤
│       完成答题后查看结果          │
└──────────────────────────────────┘
```

#### 2.3.2 作答反馈状态

**选择正确时：**

```
┌──────────────────────────┐
│  ✓  B. SYN+ACK    ← 绿色  │  ← 正确选项高亮绿色
└──────────────────────────┘
┌──────────────────────────┐
│                          │
│  ✅ 回答正确！             │  ← 成功提示
│                          │
│  TCP 三次握手的第二步是     │  ← 解析内容
│  服务器回复 SYN+ACK...     │
│                          │
└──────────────────────────┘
┌──────────────────────────┐
│       下一题 →             │
└──────────────────────────┘
```

**选择错误时：**

```
┌──────────────────────────┐
│  ✗  A. SYN        ← 红色  │  ← 错误选项高亮红色
└──────────────────────────┘
┌──────────────────────────┐
│  ✓  B. SYN+ACK    ← 绿色  │  ← 正确选项显示绿色
└──────────────────────────┘
┌──────────────────────────┐
│                          │
│  ❌ 回答错误               │  ← 失败提示
│                          │
│  正确答案是 B. SYN+ACK     │  ← 显示正确答案
│  TCP 三次握手的第二步是     │  ← 解析内容
│  服务器回复 SYN+ACK...     │
│                          │
└──────────────────────────┘
┌──────────────────────────┐
│       下一题 →             │
└──────────────────────────┘
```

#### 2.3.3 交互说明

| 元素 | 交互 | 反馈 |
|------|------|------|
| 选项 | 点击选中 | 选中状态（高亮边框 + 填充色） |
| 确认选择按钮 | 已选选项后变为可点击 | 按钮从灰色变为主题色 |
| 提交答案 | 点击提交 | 立即展示对/错 + 绿色/红色动画 |
| 解析面板 | 答题后自动展开 | 底部内容展开动画 (300ms) |
| 下一题 | 点击进入下一题 | 当前题左滑消失 + 新题右滑进入 |
| 进度 📊 | 点击查看实时统计 | 底部弹出统计卡片 |

## 7. 学习算法交互逻辑

### 7.1 间隔复习调度

```
用户答题正确:
  第1次 → 1天后复习
  第2次 → 3天后复习
  第3次 → 7天后复习
  第4次 → 14天后复习
  第5次+ → 30天后复习

用户答题错误:
  → 立即加入今日复习队列
  → 复习间隔重置为1天

每日调度:
  1. 筛选 next_review_at <= 今天 的卡片
  2. 按优先级排序: 错误次数多 > 等待天数长
  3. 限制每日新卡片数量（默认 10 张/天）
```

### 7.2 掌握度计算

```
掌握度 = 正确次数 / (正确次数 + 错误次数) × 100%

条件:
  - 学习次数 < 3 次 → 掌握度 ≤ 50% (未稳定)
  - 学习次数 ≥ 3 次 + 连续正确 ≥ 2 次 → 掌握度 70%+
  - 连续正确 ≥ 4 次 → 掌握度 90%+ (已完成)

视觉反馈:
  - < 50%: 红色进度条 → "需加强"
  - 50-80%: 黄色进度条 → "学习中"
  - > 80%: 绿色进度条 → "已掌握"
```

## 8. 设计原则总结

1. **专注优先**：学习页面去除所有干扰元素，让用户专注于卡片内容
2. **反馈即时**：每一次点击、选择、翻转都有即时的视觉/触觉反馈
3. **离线可用**：核心学习功能完全离线，不依赖网络
4. **低操作成本**：3 步内完成一次学习（打开 → 看卡片 → 点反馈）
5. **渐进式引导**：新用户通过空状态引导逐步创建内容，而不是一次性填鸭
6. **数据透明**：用户清楚看到自己的学习进度和掌握情况
