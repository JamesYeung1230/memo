# 小程序审核重新提交说明

## 修改内容

### 问题1：隐私政策合规（已修复）

**驳回原因**：默认自动同意《用户服务协议》及《隐私政策》，应当由用户自主阅读后自行选择是否同意。

**修改内容**：
1. 登录页新增复选框 `☐ 我已阅读并同意《隐私政策》及《用户服务协议》`
2. 复选框默认为**未勾选**状态
3. 登录按钮在复选框勾选前保持**禁用**状态
4. 支持点击协议名称弹出详细内容供用户阅读

**流程验证**：
```
用户打开登录页
  → 看到复选框（未勾选）+ 禁用登录按钮
  → 阅读协议内容（点击协议名称）
  → 手动点击复选框勾选
  → 登录按钮变为可点击
  → 用户点击登录
```

### 问题2：登录授权时序（已修复）

**驳回原因**：一进入首页即要求授权登录，未让用户体验浏览功能服务。

**修改内容**：
1. 移除首页 `onShow` 中的强制登录跳转逻辑
2. 未登录用户（游客）可**直接浏览首页内容**：Banner、推荐卡片等
3. 顶部显示渐变登录引导条（非模态、不阻塞浏览）
4. 仅在用户主动点击"登录"按钮时才跳转登录页
5. 登出和 Token 过期后均返回首页（游客模式），而非登录页

**用户流程验证**：
```
游客打开小程序
  → 直接进入首页，可浏览内容
  → 顶部显示：「登录后同步学习数据 / 一键微信登录，云端保存进度」[登录]
  → 用户可自由下滑浏览推荐卡片
  → 用户想使用学习记录功能时，点击顶部【登录】
  → 跳转登录页 → 勾选隐私协议 → 微信一键登录
```

## 测试步骤

1. 未登录状态下打开小程序 → 应直接进入首页，看到渐变登录条
2. 下滑浏览 → 可看到推荐卡片等公共内容
3. 点击登录条 → 跳转登录页
4. 点击「微信一键登录」→ 按钮应因未勾选协议而无法点击
5. 勾选「我已阅读并同意...」→ 登录按钮变为可点击
6. 点击协议名称 → 弹出协议内容
7. 勾选后点击登录 → 正常登录流程
