## 2. 管理员账号（auth.admin）

### 2.1 数据定义

| 字段 | 值 | 来源 |
|------|:---:|------|
| `username` | 由环境变量 `ADMIN_USERNAME` 指定 | `.env` |
| `password_hash` | 由环境变量 `ADMIN_PASSWORD_HASH` 指定（bcrypt） | `.env` |

### 2.2 初始化逻辑

```python
# 伪代码：Alembic data_migration
def upgrade():
    username = os.environ["ADMIN_USERNAME"]
    password_hash = os.environ["ADMIN_PASSWORD_HASH"]
    op.execute(
        f"INSERT INTO auth.admin (username, password_hash) "
        f"VALUES ('{username}', '{password_hash}')"
    )

def downgrade():
    op.execute("DELETE FROM auth.admin WHERE username = 'admin'")
```

> **安全性说明**：`password_hash` 已经过 bcrypt 哈希处理，迁移脚本中直接写入哈希值而非明文密码。生产环境中 `ADMIN_PASSWORD_HASH` 通过环境变量注入，不硬编码在代码中。

## 4. 积分规则默认值（core.config）

### 4.1 points_rules

对应 PRD-webapp §3.4.1 全部 12 个积分配置项：

```json
{
    "learn_card": 1,
    "daily_learn_card_limit": 10,
    "daily_challenge": 15,
    "daily_challenge_limit": 15,
    "create_note": 5,
    "daily_create_note_limit": 15,
    "ad_watch": 10,
    "daily_ad_watch_limit": 100
}
```

**配置项说明**：

| 键 | 类型 | 默认值 | 可配范围 | 对应行为 |
|----|:----:|:-----:|:--------:|---------|
| `learn_card` | int | 1 | 1~5 | 学习 1 张卡片（点「懂了」）|
| `daily_learn_card_limit` | int | 10 | 5~30 | 学习卡片每日上限 |
| `daily_challenge` | int | 15 | 10~30 | 每日挑战全对奖励 |
| `daily_challenge_limit` | int | 15 | 10~30 | 每日挑战每日上限 |
| `create_note` | int | 5 | 1~10 | 创建笔记（≥20 字）|
| `daily_create_note_limit` | int | 15 | 5~30 | 创建笔记每日上限 |
| `ad_watch` | int | 10 | 5~20 | 观看激励广告 |
| `daily_ad_watch_limit` | int | 100 | 50~200 | 观看广告每日上限 |

### 4.2 checkin_milestones

对应 PRD-webapp §3.4.1 连续打卡里程碑：

```json
{
    "3": 15,
    "7": 30,
    "14": 60
}
```

| 键 | 值 | 说明 |
|:--:|:--:|------|
| `3` | 15 | 连续打卡第 3 天奖励 15 积分 |
| `7` | 30 | 连续打卡第 7 天奖励 30 积分 |
| `14` | 60 | 连续打卡第 14 天奖励 60 积分 |

## 5. 默认复习计划（core.config）

### 5.1 default_review_config

对应 PRD-miniapp §2.3.3 复习计划配置：

```json
{
    "review_nodes": [1, 2, 4, 7, 15],
    "daily_limit": 20,
    "forgotten_alert_days": 7,
    "reminder_time": "20:00",
    "weekend_quiet": false
}
```

| 键 | 类型 | 默认值 | 可配范围 | 说明 |
|----|:----:|:-----:|:--------:|------|
| `review_nodes` | array | `[1,2,4,7,15]` | 1~5 个节点，每节点 1~60 天 | 复习节点（学习后第 N 天）|
| `daily_limit` | int | 20 | 5~50 | 每日复习上限（张）|
| `forgotten_alert_days` | int | 7 | 3~30 | 遗忘预警天数 |
| `reminder_time` | string | `"20:00"` | 08:00~22:00 | 每日提醒时间 |
| `weekend_quiet` | bool | `false` | — | 周末免打扰 |
