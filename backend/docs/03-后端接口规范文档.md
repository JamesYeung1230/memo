## 1. 通用规范

### 1.1 基础 URL

| 服务 | 基础 URL | 可见性 |
|------|----------|:------:|
| Auth Service | `http://auth:8001/api/v1` | 对外（小程序 + Web）|
| Core Service | `http://core:8000/api/v1` | 对外（小程序 + Web）|
| Knowledge Service | `http://knowledge:8002/api/v1` | 对内（仅 Core 调用）|

### 1.2 统一请求头

```
Content-Type: application/json
Authorization: Bearer <jwt_token>  （需要认证的接口）
X-Request-ID: <uuid>               （可选，链路追踪）
```

### 1.3 统一响应格式

**成功响应**：
```json
{
    "data": {},
    "meta": {
        "page": 1,
        "page_size": 20,
        "total": 100
    }
}
```

**错误响应**：
```json
{
    "error": {
        "code": "ERROR_CODE",
        "message": "Human readable message",
        "detail": {}
    }
}
```

### 1.4 分页规范

| 参数 | 类型 | 默认值 | 最大值 | 说明 |
|------|:----:|:-----:|:-----:|------|
| page | int | 1 | — | 页码，从 1 开始 |
| page_size | int | 20 | 100 | 每页条数 |

### 1.5 通用状态码

| 状态码 | 说明 |
|:-----:|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 204 | 删除成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或 Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如名称重复）|
| 422 | 请求体验证失败 |
| 429 | 请求频率超限 |
| 500 | 服务内部错误 |

#### 3.6.1 通用文件上传规范

所有图片类上传接口遵循统一的请求/响应格式和约束。

**通用约束**：

| 维度 | 规范 |
|------|------|
| 请求格式 | `multipart/form-data`（字段名: `file`） |
| 允许格式 | JPG / JPEG / PNG / WebP / GIF |
| 单文件上限 | 2MB |
| 推荐尺寸 | Banner: 750×300px；徽章图标: 建议正方形 200×200px |
| 认证要求 | 需要 Admin JWT |

**Request**（以 Banner 上传为例）：
```
POST /api/v1/admin/banners/{id}/upload
Content-Type: multipart/form-data
Authorization: Bearer <admin_jwt>

file: <binary_image_data>
```

**Response `200`**：
```json
{
    "data": {
        "url": "/static/banners/{banner_id}_{uuid}.jpg"
    }
}
```

**错误响应**：
```json
{
    "error": {
        "code": "VALIDATION_ERROR",
        "message": "不支持的图片格式，仅允许 JPG/PNG/WebP/GIF",
        "detail": {}
    }
}
```

> **URL 说明**：返回的 URL 为相对路径，客户端需拼接 Core 服务基础地址。文件通过 Core 服务的 FastAPI StaticFiles 挂载对外提供访问，无需额外文件服务。

**成就徽章上传**与 Banner 上传共用同一套逻辑，仅存储目录不同：
| 业务类型 | 端点 | 存储目录 |
|---------|------|----------|
| Banner 图片 | `POST /api/v1/admin/banners/{id}/upload` | `/data/uploads/banners/` |
| 成就徽章图标 | `POST /api/v1/admin/achievements/{id}/upload` | `/data/uploads/achievements/` |

## 5. 小程序客户端调用流程

```
 小程序启动
    │
    ├── GET  /api/v1/config/banners        （取 Banner）
    ├── GET  /api/v1/config/theme           （取主题色）
    ├── GET  /api/v1/config/announcement    （取公告）
    │
    ├── POST /api/v1/login     {code}       （登录拿 JWT）
    │         → 返回 access_token + refresh_token
    │
    │   心跳 → 用 access_token 调用业务 API
    │         → 401 → 自动用 refresh_token 换新 token
    │
    ├── GET  /api/v1/learn/domains          （首页加载学习进度）
    ├── GET  /api/v1/learn/cards/{id}       （打开卡片）
    ├── POST /api/v1/learn/cards/{id}/master（点「懂了」→ 积分+1）
    ├── POST /api/v1/quiz/submit            （答题 → 积分+15 全对）
    ├── POST /api/v1/notes                  （创建笔记）
    ├── POST /api/v1/notes/{id}/submit-review（提交笔记审核）
    └── ...
```
