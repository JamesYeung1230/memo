**拆解任务**：

- [ ] **1.1 在 Ubuntu 上安装 Docker 和 Docker Compose**
  - 执行命令安装 Docker：
    ```bash
    curl -fsSL https://get.docker.com -o get-docker.sh
    sudo sh get-docker.sh
    sudo usermod -aG docker $USER
    # 退出终端重新登录，或执行 newgrp docker 使组权限生效
    ```
  - 验证安装：`docker --version`（应显示 24.x+）
  - 安装 Docker Compose Plugin（通常已随 Docker 安装）：`docker compose version`
  - 验证：`docker compose version`（应显示 2.x+）

- [ ] **1.2 将项目从 Windows 复制到 Ubuntu**
  - 方式 A（推荐 — 使用 Git）：
    ```bash
    # 在 Windows 上执行 git commit（确保所有改动已提交）
    # 在 Windows 上推送到远程仓库（GitHub/Gitee）
    # 在 Ubuntu 上拉取
    git clone <仓库地址> ~/workspace/memo/backend
    ```
  - 方式 B（无远程仓库 — 使用 scp）：
    ```bash
    # 在 Windows PowerShell 上执行（管理员权限）
    scp -r d:\workspace\memo\backend ubuntu-user@<ubuntu-ip>:~/workspace/memo/
    ```

- [ ] **1.3 配置 Ubuntu 环境变量**
  - 进入项目目录：`cd ~/workspace/memo/backend`
  - 复制环境变量模板：`cp .env.example .env`
  - 生成 `ADMIN_PASSWORD_HASH`：
    ```bash
    # 先安装 bcrypt（如果没装 Python 的话）
    sudo apt install python3-pip -y
    pip3 install bcrypt
    python3 -c "import bcrypt; print(bcrypt.hashpw(b'admin123', bcrypt.gensalt(rounds=12)).decode())"
    ```
  - 将输出的哈希值填入 `.env` 文件的 `ADMIN_PASSWORD_HASH=` 后面
  - 修改 `.env` 中以下变量为 Ubuntu 本地值：
    ```
    DB_HOST=localhost
    REDIS_HOST=localhost
    KNOWLEDGE_SERVICE_URL=http://localhost:8002
    UPLOAD_DIR=./uploads
    ```

- [ ] **1.4 创建项目目录结构（准备 Docker 挂载）**
  ```bash
  mkdir -p ~/workspace/memo/backend/uploads
  ```
