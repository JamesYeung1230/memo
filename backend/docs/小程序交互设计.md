## 第1章 设计系统（Design Tokens）

### 1.1 色彩系统

> 主题色由管理端动态下发（PRD §2.5.3），以下为默认品牌色体系。

| Token 名称 | 色值 | 用途 |
|-----------|------|------|
| `--color-primary` | `#4A90D9` | 品牌主色：导航栏、TabBar 选中态、按钮、强调文字、进度条 |
| `--color-primary-light` | `#7AB8F5` | 主色浅色：选中背景、标签底色 |
| `--color-primary-dark` | `#2D6EC9` | 主色深色：按钮按压态 |
| `--color-secondary` | `#6C63FF` | 辅色：部分强调元素、积分/成就模块点缀 |
| `--color-success` | `#22C55E` | 成功/通过：审核通过、答题正确、打卡完成 |
| `--color-warning` | `#F59E0B` | 警告/审核中：待审核、预警提示 |
| `--color-error` | `#EF4444` | 错误/驳回：答题错误、审核驳回、删除确认 |
| `--color-bg-page` | `#F5F6FA` | 页面背景色 |
| `--color-bg-card` | `#FFFFFF` | 卡片/列表项背景色 |
| `--color-bg-elevated` | `#FFFFFF` | 浮层/弹窗背景色 |
| `--color-text-primary` | `#1E293B` | 主文字色（标题、正文） |
| `--color-text-secondary` | `#64748B` | 次要文字色（描述、时间、辅助信息） |
| `--color-text-hint` | `#94A3B8` | 提示/占位文字色 |
| `--color-text-on-primary` | `#FFFFFF` | 主色上的文字（反白） |
| `--color-divider` | `#E2E8F0` | 分割线/边框 |
| `--color-mask` | `rgba(0,0,0,0.5)` | 遮罩层 |

**主题色动态切换规则**：
- 运营端下发主题色值后，替换 `--color-primary` 及其衍生色（light/dark 通过算法自动计算 ±15% 亮度）
- 组件中统一通过 CSS 变量引用，不硬编码色值
- 默认值兜底：接口未返回或加载失败时使用品牌蓝 #4A90D9

### 1.2 字体系统

小程序使用系统默认字体（微信原生），通过 `font-weight` 控制层级。

| Token 名称 | 字号 | 字重 | 行高 | 用途 |
|-----------|------|------|------|------|
| `--font-display` | 36rpx | 700 | 1.2 | 大标题（页面主标题） |
| `--font-h1` | 32rpx | 600 | 1.3 | 一级标题（卡片标题、章节标题） |
| `--font-h2` | 28rpx | 600 | 1.4 | 二级标题（小节标题、模块标题） |
| `--font-body` | 28rpx | 400 | 1.6 | 正文（卡片内容、题目、说明文字） |
| `--font-body-bold` | 28rpx | 600 | 1.6 | 正文强调 |
| `--font-caption` | 24rpx | 400 | 1.5 | 辅助文字（时间、标签、状态、提示） |
| `--font-caption-bold` | 24rpx | 600 | 1.5 | 辅助文字强调 |
| `--font-tag` | 20rpx | 500 | 1.4 | 标签/徽章文字 |
| `--font-number` | 48rpx | 700 | 1.2 | 数字展示（积分数、正确率） |

> **设计决定**：目标用户含传统开发人员与产品经理，设计风格应偏专业、清晰、现代，而非可爱风格（Claymorphism 不适用）。参考 Swiss Modernism 2.0 的网格体系与 Micro SaaS 的配色逻辑。

### 1.3 间距系统

基于 8rpx 基准单位。

| Token 名称 | 值 | 用途 |
|-----------|-----|------|
| `--space-xs` | 8rpx | 极小间距：图标与文字、标签内边距 |
| `--space-sm` | 16rpx | 小间距：列表项内部、紧凑排列 |
| `--space-md` | 24rpx | 中间距：卡片内边距、表单项间距 |
| `--space-lg` | 32rpx | 大间距：模块间距、页面左右边距 |
| `--space-xl` | 48rpx | 超大间距：段落间距、模块组间距 |

### 1.4 圆角系统

| Token 名称 | 值 | 用途 |
|-----------|-----|------|
| `--radius-sm` | 8rpx | 标签、徽章、小按钮 |
| `--radius-md` | 16rpx | 卡片、列表项、输入框、中等按钮 |
| `--radius-lg` | 24rpx | 弹窗、底部面板、大卡片 |
| `--radius-xl` | 30rpx | 特殊强调容器（品牌规范） |
| `--radius-full` | 9999rpx | 胶囊按钮、头像、圆形图标 |

### 1.5 阴影系统

| Token 名称 | 值 | 用途 |
|-----------|-----|------|
| `--shadow-none` | `none` | 平面元素 |
| `--shadow-sm` | `0 2rpx 8rpx rgba(0,0,0,0.06)` | 列表项悬浮、轻微分层 |
| `--shadow-md` | `0 4rpx 16rpx rgba(0,0,0,0.08)` | 卡片、浮层 |
| `--shadow-lg` | `0 8rpx 32rpx rgba(0,0,0,0.12)` | 弹窗、底部面板 |

### 1.6 动效规范

| 场景 | 时长 | 缓动函数 | 说明 |
|------|------|---------|------|
| 页面转场 | 300ms | `ease-out` | 左右滑动进入/退出 |
| 卡片翻转 | 400ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 知识卡片 3D 翻转 |
| 按钮点击 | 150ms | `ease-out` | 缩放至 95% + 颜色变深 |
| 弹窗出现 | 250ms | `ease-out` | 从下往上弹出 / 从中心缩放出现 |
| 弹窗消失 | 200ms | `ease-in` | 反向动画 |
| Toast 出现 | 200ms | `ease-out` | 顶部滑入 |
| Toast 消失 | 200ms | `ease-in` | 顶部滑出 / 渐隐 |
| 列表项删除 | 300ms | `ease-in-out` | 高度收缩 + 渐隐 |
| 进度条填充 | 600ms | `ease-out` | 从 0 填充至目标值 |
| 骨架屏 | — | `animate-pulse` | 呼吸动画，无限循环 |
| 数字滚动 | 800ms | `ease-out` | 积分/统计数据变化时 |

> **可访问性**：所有动效需响应 `prefers-reduced-motion: reduce`，此时禁用非必要动画或缩短至 0ms。

### 3.2 核心组件规格

#### C03 knowledge-card（知识卡片）

| 属性 | 规格 |
|------|------|
| 尺寸 | 宽度 `100% - 64rpx`（左右各 32rpx），高度自适应（最小 300rpx） |
| 圆角 | `--radius-lg` (24rpx) |
| 阴影 | `--shadow-md` |
| 背景 | `--color-bg-card` |
| 内容区 | 标题（`--font-h1`）、核心概念（一句话，`--font-body-bold` + `--color-primary`）、详细说明（2~3段，`--font-body`）、类比场景（`--font-caption` + `--color-text-secondary`）、关键词标签（C10 tag 组） |
| 底部操作栏 | 「懂了」按钮（实心主色）+「收藏」按钮（线框/图标） |
| 交互状态 | 默认态 → 滑动进入（translateX + opacity 300ms ease-out）；点击卡片展开详情的区域有 hover 态（小程序内为 tap 态，背景微变）；「懂了」点击后卡片标记为已掌握，卡片增加绿色边框和 ✓ 标记 |

#### C04 progress-ring（环形进度条）

| 属性 | 规格 |
|------|------|
| 尺寸 | 默认 160rpx × 160rpx，可配置 |
| 线条宽度 | 12rpx |
| 底色 | `--color-divider` |
| 进度色 | `--color-primary`（可覆盖为 `--color-success` 完成态） |
| 动画 | 从 0 填充至目标值，600ms ease-out |
| 中心文字 | 百分比数字（`--font-number`）+ 副标题（`--font-caption`） |

#### C14 modal（居中弹窗）

| 属性 | 规格 |
|------|------|
| 宽度 | 560rpx（最大） |
| 圆角 | `--radius-lg` (24rpx) |
| 遮罩 | `--color-mask`，点击遮罩可关闭（可配置 `maskClosable`） |

#### C17 quiz-option（答题选项）

| 属性 | 规格 |
|------|------|
| 尺寸 | 宽度 100%，高度 ≥ 88rpx |
| 圆角 | `--radius-md` (16rpx) |

### 3.3 按钮规范

| 类型 | 样式 | 使用场景 |
|------|------|---------|
| **主按钮（Primary）** | 实心主色背景 + 白色文字，圆角 `--radius-full`，高度 88rpx | 页面主要操作：提交审核、开始答题、确认解锁 |
| **次按钮（Secondary）** | 线框主色 + 主色文字，圆角 `--radius-full`，高度 88rpx | 辅助操作：查看详情、稍后再说 |
| **文字按钮（Text）** | 纯文字，无背景无边框，主色/灰色 | 导航操作：查看更多、跳过、取消 |
| **图标按钮（Icon）** | 仅图标，32~48rpx | 收藏、分享、更多操作 |
| **危险按钮（Danger）** | 实心红色 + 白色文字 | 删除、退出 |
| **置灰按钮（Disabled）** | 灰色背景 + 灰色文字，不可点击 | 审核中/已驳回时的分享按钮、积分不足时的解锁按钮 |

**按钮交互反馈**：
- 点击态（tap）：缩放至 95%（`transform: scale(0.95)`），150ms ease-out
- 加载态：按钮内显示 loading-spinner（C08），禁止重复点击
- 不可用态：置灰，`pointer-events: none`

## 第6章 状态与边界情况

### 6.1 网络状态

| 状态 | 处理方式 |
|------|---------|
| 网络正常 | 正常请求 |
| 网络断开 | Toast「网络连接失败，请检查网络」；不影响本地操作（笔记编辑、学习记录） |
| 请求超时 | Toast「请求超时，请重试」；本地数据兜底展示 |
| 接口异常 | 非关键操作使用缓存数据；关键操作 Toast 提示重试 |

### 6.2 数据状态

| 状态 | 组件 | 说明 |
|------|------|------|
| 加载中 | C07 skeleton / C08 spinner | 首次加载展示骨架屏（列表 3 项占位），二次加载展示 spinner |
| 数据为空 | C06 empty-state | 差异化文案，不同页面不同引导 |
| 数据错误 | C06 + 重试按钮 | 「加载失败，点击重试」 |
| 列表到底 | 底部文字 | 「—— 已加载全部 ——」 |
| 数据过期 | 下拉刷新 | 下拉手势触发刷新，顶部 spinner 反馈 |

### 6.3 权限状态

| 权限 | 处理 |
|------|------|
| 订阅消息（复习提醒） | 未授权时弹窗 M14 引导，拒绝后可在设置中重新开启 |
| 相册/拍照（头像） | 未授权时弹窗引导至系统设置 |
| 存储空间不足 | Toast「存储空间不足，请清理后重试」 |

### 6.4 笔记相关边界

| 边界情况 | 处理 |
|---------|------|
| 字数超限（>5000） | 输入框底部红字提示「已超出 XXX 字」，提交按钮置灰 |
| 笔记数量达上限（500条） | Toast「笔记数量已达上限（500条），请删除后继续」；新建按钮置灰 |
| 关联知识被移除 | 保留笔记正文，去除关联链接，标注「原关联知识已移除」 |
| 审核中编辑笔记 | 允许编辑，但提交审核后原审核流程自动撤回 |
| 已通过笔记编辑 | 分享状态重置，需重新提交审核 |
| 连续3次审核驳回 | 分享功能冻结7天，M15 弹窗通知 |

### 6.5 积分相关边界

| 边界情况 | 处理 |
|---------|------|
| 积分不足解锁 | 按钮置灰 + 文案「积分不足，还差 XX 积分」+ 看广告入口 |
| 每日积分达上限 | 行为积分不再增加，不提示（静默处理） |
| 每日挑战已达上限 | 入口置灰 + 「今日已完成」 |
| 看广告日上限（10次） | 按钮置灰 + 「今日已达上限」 |

### 9.2 设计决策说明

| 决策点 | 结论 | 理由 |
|--------|------|------|
| 卡片滑动方向 | 垂直上下滑动 | 微信小程序用户习惯上下滚动；横向滑动与 Banner 轮播冲突 |
| 风格选择 | Swiss Modernism + Micro SaaS | 目标用户含开发人员/产品经理，需专业现代感，Claymorphism 偏儿童化不适合 |
| Tab 数量 | 5 个 | 覆盖 PRD 全部核心功能：首页/学习/笔记/积分/个人中心 |
| 字体 | 系统默认 | 微信小程序限制，系统字体（PingFang SC / Microsoft YaHei）足以满足需求 |
| 弹窗 vs 页面 | 审核流程用弹窗 | 审核是操作流中的打断点，弹窗比跳页更符合心智模型 |
| 主题色 | CSS 变量动态切换 | 运营端下发主题色需实时生效，CSS 变量无需重新编译 |
