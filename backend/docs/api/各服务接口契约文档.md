## 1. 契约概述

### 1.1 调用链路

```
Auth(:8001) ◄── 客户端直接调用（登录/刷新/密码修改）
Core(:8000) ◄── 客户端携带 JWT 调用（全业务 API）
Knowledge(:8002) ◄── Core 内部 httpx 调用（内容管理/AI生成/审核）
```

### 1.2 契约总表

| 契约分类 | 接口数 | 调用方 | 提供方 |
|---------|:-----:|:------:|:------:|
| 内容查询（小程序端）| 5 | Core | Knowledge |
| 内容管理（Web 管理端）| 26 | Core | Knowledge |
| AI 内容生成 | 4 | Core | Knowledge |
| 敏感词库管理 | 7 | Core | Knowledge |
| 笔记审核 | 12 | Core | Knowledge |
| **合计** | **54** | | |

### 1.3 约定

- 内部服务请求使用 Docker Compose 服务名 hostname：`http://knowledge:8002`
- 请求头：`Content-Type: application/json`，**不需要 JWT**
- Core 和 Knowledge 在同一 Docker 网络，无需鉴权
- 所有接口路径前缀：`/api/v1`
- 错误时返回统一格式错误码（见 §6 错误码）

### 1.4 错误码

| 错误码 | 含义 | Core 处理策略 |
|--------|------|-------------|
| `KNOWLEDGE_NOT_FOUND` | 资源不存在 | 透传 404 给客户端 |
| `KNOWLEDGE_VALIDATION_ERROR` | 参数校验失败 | 透传 422 给客户端 |
| `KNOWLEDGE_DUPLICATE` | 名称重复 | 返回 409 Conflict（如章节重名）|
| `KNOWLEDGE_INTERNAL_ERROR` | 内部错误 | 返回 500 给客户端 |
| `KNOWLEDGE_AI_ERROR` | AI 生成失败 | 返回 502 + 重试提示 |
| `KNOWLEDGE_SENSITIVE_HIT` | 命中敏感词 | 返回 400 + 命中词列表 |
| `KNOWLEDGE_UNSAFE_CONTENT` | AI 审核高风险 | 返回 400 + 风险详情 |

### 5.2 笔记审核流水线

#### 提交笔记审核

**Core → Knowledge**：`POST /api/v1/review/notes/{note_id}/submit`

Request：
```json
{
    "note_id": "core_db_的_note_id",
    "title": "笔记标题",
    "content": "笔记正文全文",
    "author_id": "用户的_openid"
}
```

此接口内部执行三级审核流程并返回结果：

Response `200`：
```json
{
    "data": {
        "review_id": "uuid",
        "status": "approved|rejected|pending_manual",
        "risk_score": 15,
        "risk_labels": [],
        "review_detail": {
            "sensitive_words_hit": [],
            "ai_risk_score": 15,
            "ai_risk_labels": [],
            "ai_reasoning": "内容正常，无违规...",
            "needs_manual_review": false
        }
    }
}
```

**状态流转说明**：

| 返回 status | 含义 | Core 应执行的操作 |

| `approved` | 审核通过 | 更新 core_db note 状态为 approved，通知用户 |
| `rejected` | 审核驳回 | 更新 core_db note 状态为 rejected，记录原因 |
| `pending_manual` | 人工复核中 | 更新 core_db note 状态为 reviewing，提示用户等待 |

## 6. Core 服务 KnowledgeClient 实现规范

Core 服务中的 `KnowledgeClient` 应封装所有对 Knowledge 的调用：

```python
class KnowledgeClient:
    def __init__(self, base_url: str = "http://knowledge:8002"):
        self.client = httpx.AsyncClient(base_url=base_url, timeout=30.0)
    
    # === 内容查询 ===
    async def get_domains(self, status: str = "published") -> list[DomainOut]:
        resp = await self.client.get("/api/v1/domains", params={"status": status})
        return self._handle_response(resp, list[DomainOut])
    
    async def get_chapters(self, domain_id: str) -> list[ChapterOut]:
        resp = await self.client.get(f"/api/v1/domains/{domain_id}/chapters")
        return self._handle_response(resp, list[ChapterOut])
    
    async def get_cards(self, chapter_id: str) -> list[CardOut]:
        resp = await self.client.get(f"/api/v1/chapters/{chapter_id}/cards")
        return self._handle_response(resp, list[CardOut])
    
    async def get_card_detail(self, card_id: str) -> CardDetailOut:
        resp = await self.client.get(f"/api/v1/cards/{card_id}")
        return self._handle_response(resp, CardDetailOut)
    
    async def get_question(self, card_id: str) -> QuestionOut:
        resp = await self.client.get(f"/api/v1/cards/{card_id}/question")
        return self._handle_response(resp, QuestionOut)
    
    # === 内容管理 ===
    async def create_domain(self, data: DomainCreate) -> DomainOut:
        resp = await self.client.post("/api/v1/domains", json=data.model_dump())
        return self._handle_response(resp, DomainOut)
    
    async def update_domain(self, domain_id: str, data: DomainUpdate) -> DomainOut:
        resp = await self.client.put(f"/api/v1/domains/{domain_id}", json=data.model_dump())
        return self._handle_response(resp, DomainOut)
    
    async def delete_domain(self, domain_id: str) -> None:
        resp = await self.client.delete(f"/api/v1/domains/{domain_id}")
        resp.raise_for_status()
    
    # ... 章节、卡片、题目同理
    
    # === AI 生成 ===
    async def generate_cards(self, topics: list[str], chapter_id: str) -> list[AIGeneratedCard]:
        resp = await self.client.post("/api/v1/ai/generate-cards", json={
            "topics": topics,
            "chapter_id": chapter_id,
            "mode": "sync"
        }, timeout=120.0)
        return self._handle_response(resp, AIGenerateResult)
    
    # === 审核 ===
    async def submit_review(self, note_id: str, title: str, content: str, author_id: str) -> ReviewResult:
        resp = await self.client.post(f"/api/v1/review/notes/{note_id}/submit", json={
            "note_id": note_id,
            "title": title,
            "content": content,
            "author_id": author_id
        })
        return self._handle_response(resp, ReviewResult)
    
    async def approve_review(self, review_id: str, reviewer: str) -> ReviewStatus:
        resp = await self.client.post(f"/api/v1/review/notes/{review_id}/approve", json={
            "reviewer": reviewer
        })
        return self._handle_response(resp, ReviewStatus)
    
    async def reject_review(self, review_id: str, reviewer: str, reason: str) -> ReviewStatus:
        resp = await self.client.post(f"/api/v1/review/notes/{review_id}/reject", json={
            "reviewer": reviewer,
            "reason": reason
        })
        return self._handle_response(resp, ReviewStatus)
    
    async def get_review_queue(self, page: int = 1, page_size: int = 20) -> ReviewQueueResult:
        resp = await self.client.get("/api/v1/review/queue", params={
            "page": page, "page_size": page_size
        })
        return self._handle_response(resp, ReviewQueueResult)
    
    async def get_review_statistics(self) -> ReviewStatistics:
        """用于 Core 数据看板审核统计"""
        resp = await self.client.get("/api/v1/review/statistics")
        return self._handle_response(resp, ReviewStatistics)
    
    # ... 其余接口同理
    
    def _handle_response(self, resp: httpx.Response, model: type[T]) -> T:
        if resp.is_success:
            data = resp.json().get("data")
            return model.model_validate(data)
        else:
            error = resp.json().get("error", {})
            raise KnowledgeServiceException(
                code=error.get("code"),
                message=error.get("message"),
                status_code=resp.status_code
            )
```

## 7. 契约变更流程

1. **Knowledge 服务**新增/修改/删除接口时，必须先更新本文档
2. 变更后通知 **Core 服务**更新 `KnowledgeClient`
3. 向后兼容变更（新增可选字段、新增接口）**无需版本号**
4. 不兼容变更（删除字段、修改字段类型）**必须增加 URL 版本号**（如 `/api/v2/`）
