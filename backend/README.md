# 卡片学记 — 后端服务

## 项目简介

本目录是「卡片学记」平台的 **后端 API 服务**，为微信小程序和 Web 端管理后台提供统一的 REST API 接口。

「卡片学记」是一个基于知识卡片 + 选择题测验的学习工具平台，利用**主动回忆 (Active Recall)** 和**间隔重复 (Spaced Repetition)** 两大认知科学原理，帮助用户高效记忆和理解知识。
