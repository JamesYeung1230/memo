## 项目定位

测试工程是「码上启航」平台的**独立测试项目**，负责对所有子项目的后端接口和前端交互进行测试验证与 Bug 上报。

## 测试范围划分

| 测试对象 | 测试模块 | 测试类型 | 测试方式 | 说明 |
|----------|---------|----------|----------|------|
| 后端 SDK API | 全部 API 接口 | 接口测试 | 编写测试用例 + 测试代码，自动化执行 | 依照后端 SDK 文档编写测试用例，完成测试并上报 Bug |
| 微信小程序 (miniapp) | 首页个性化配置（Banner/模块排序/主题色）、知识卡片学习、刷题学习、记忆强化、笔记管理（含三级审核）、积分体系、广告展示、个人中心 | 黑盒测试 | 编写测试用例，告知用户执行 | 根据 PRD 与交互设计文档编写测试用例，由用户手动执行 |
| Web 管理后台 (webapp) | 管理员登录、AI 内容工作台（卡片生成/题目生成/笔记审核/敏感词库）、内容管理（领域/章节/卡片/题目）、运营配置（积分/解锁/Banner/徽章/广告）、数据看板（核心指标/内容/用户/广告数据）、系统管理 | 黑盒测试 | Playwright MCP 自动化测试 | 依据 Web 管理端 PRD 编写 Playwright 测试脚本，自主执行并上报 Bug |

## 项目结构

```
test/
├── project.md                 # 本文件
├── pytest.ini                 # Pytest 配置（标记：smoke/auth/wechat/admin/knowledge）
├── requirements.txt           # Python 依赖（pytest + httpx + python-dotenv）
├── .env / .env.example        # 环境变量
├── docs/                      # 测试文档（测试用例、PRD、API 契约等）
├── tests/
│   ├── conftest.py            # 会话级 fixtures（ApiClient、admin_token 等）
│   ├── utils/client.py        # ApiClient（httpx 封装）+ ApiResponse
│   ├── auth/                  # Auth 服务测试 (8001)：6 文件 36 用例
│   ├── knowledge/             # Knowledge 服务测试 (8002)：7 文件 51 用例
│   └── core/                  # Core 服务测试 (8000)：1 文件 1 用例
└── venv/                      # Python 虚拟环境
```
