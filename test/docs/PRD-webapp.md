## 一、产品概述

### 1.1 产品名称

**码上启航 — 运营管理后台**（CodeSail Admin）

### 1.2 产品定位

一款面向「码上启航」微信小程序管理员的 **Web 端内容管理与运营配置后台**，提供知识内容的全生命周期管理、运营策略的灵活配置以及核心数据指标的实时监控能力。

### 1.3 目标用户

| 用户角色 | 特征描述 | 核心诉求 |
|---------|---------|---------|
| 运营者 | 负责知识内容创建维护、积分与运营策略配置、数据监控 | 一站式管理内容与运营配置 |

> **说明**：本项目为个人项目，不涉及多账号/多角色管理，单一管理员账号即拥有全部操作权限。

### 1.4 与小程序的关系

```

│   码上启航 微信小程序         │      │   码上启航 Web 管理端          │

│                              │ 数据  │                              │
```

### 1.5 产品核心价值

1. **AI驱动内容生产**：知识卡片与题目内容通过AI工作流辅助生成，降低人工创作成本
2. **运营策略灵活**：积分规则、解锁消耗、广告策略等核心参数可在后台直接调整，无需发版
3. **AI审核保障安全**：用户笔记经由敏感词过滤 + AI审查 + 人工复核三级审核，审核不通过时内容仅自己可见，确保平台内容安全
4. **数据驱动决策**：学习数据、积分数据、用户数据、广告数据可视化呈现，指导运营方向

## 三、功能详细需求

### 3.1 登录

#### 3.1.1 登录方式

| 功能点 | 描述 |
|-------|------|
| 账号密码登录 | 管理员使用预设账号（用户名 + 密码）登录管理后台 |
| 登录态保持 | Token 有效期 24 小时，支持刷新 |
| 登出 | 主动登出清除本地 Token |

> **说明**：本系统为个人项目，仅支持单一管理员账号，系统启动时预设，无需账号注册和新建流程。

---

### 3.2 AI 内容工作台

#### 3.2.1 AI 知识卡片生成

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| AI生成入口 | 管理员输入知识主题或关键词，触发AI工作流生成知识卡片内容 | 支持批量输入多个主题（上限10个）交由AI依次生成 |
| AI生成结果预览 | 展示AI生成的卡片标题、核心概念、详细说明、生活类比、关键词标签、难度等级 | 管理员可逐字段编辑修改 |
| 一键采纳 | 确认无误后将AI生成内容转为正式知识卡片 | 需选择所属章节后保存；支持部分采纳（仅采纳满意字段） |
| 重新生成 | 对不满意的内容可要求AI重新生成 | 保留历史生成记录，管理员可选择不同版本 |

**AI工作流说明**：
知识卡片的创建将采用AI工作流模式——管理员提供主题方向，AI自动完成内容结构化输出（标题→核心概念→详细说明→生活类比→关键词→难度判定），管理员只需审核与微调，大幅降低内容创作门槛与时间成本。AI生成的内容可追踪来源，支持后续迭代优化提示词模板。

#### 3.2.2 AI 题目生成

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 基于卡片生成题目 | 选择已有知识卡片，AI自动生成配套单选题 | 自动填充题干、4个选项、正确答案及解析 |
| 审核与编辑 | 管理员审核AI生成的题目，修改后保存 | 可直接调整选项内容、更换正确答案 |
| 一键采纳 | 确认无误后保存为正式题目 | 自动关联对应知识卡片 |

#### 3.2.3 AI 审核管理（用户笔记）

**审核模型**

与小程序端统一采用以下审核模型：笔记提交后自动触发AI审查，不通过时笔记仅用户自己可见，需经人工复核通过后方可分享。

```
用户提交笔记
     │
     ▼
┌──────────────┐
│ 敏感词过滤    │ ── 命中 ──→ 驳回（仅自己可见）
└──────────────┘
     │ 未命中
     ▼
┌──────────────┐
│ AI内容审查    │ ── 高风险 ──→ 驳回（仅自己可见）
└──────────────┘
     │ 中/低风险
     ▼
┌──────────────┐
│ 人工复核队列  │
└──────────────┘
     │
 ┌───┴───┐
 ▼       ▼
通过    驳回（附原因）
 │       │
 ▼       ▼
可分享   仅自己可见
```

**功能详情**

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 审核队列 | 表格展示待人工复核的笔记列表 | 显示笔记标题（截断30字）、作者OpenID、提交时间、AI风险评分、AI风险类型标签 |
| 审核详情 | 查看笔记全文、AI审查结果、敏感词命中位置 | 展示AI风险评分（百分制）、AI判定理由、怀疑敏感词高亮 |
| 通过操作 | 笔记状态变为「审核通过」，分享功能恢复 | 通过后用户可在小程序端正常分享 |
| 驳回操作 | 填写驳回原因，笔记状态变为「审核驳回」 | 驳回原因展示给用户，用户可修改后重新提交 |
| 审核记录 | 表格展示全部审核历史（含通过和驳回） | 支持按审核状态、时间范围筛选 |
| 批量操作 | 支持勾选多条笔记批量通过或批量驳回 | 批量驳回时统一填写驳回原因 |

**审核统计**

| 指标 | 说明 |
|------|------|
| 今日待审核数 | 当前人工复核队列中的笔记数量 |
| 今日已审核数 | 当日已完成审核的笔记数量 |
| 审核通过率 | 近7日人工复核通过比例 |
| AI准确率参考 | AI标记中风险后人工确认违规的比例 |

> **核心原则**：审核不通过时笔记仅用户自己可见，不可分享、不可转发。只有审核通过的笔记才能被分享。

#### 3.2.4 敏感词库管理

**功能概述**

运营者维护敏感词库，支持增删改查。词库变更后实时生效于审核流程的「敏感词过滤」环节。

**功能详情**

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 词库列表 | 表格展示全部敏感词，支持搜索 | 按添加时间倒序，分页展示 |
| 新增敏感词 | 输入敏感词文本，选择匹配模式 | 精确匹配 / 拼音匹配 / 谐音匹配 / 正则表达式 |
| 编辑敏感词 | 修改敏感词文本或匹配模式 | 修改后立即生效 |
| 删除敏感词 | 删除单个或批量删除 | 需二次确认 |
| 启用/停用 | 单个敏感词可临时停用 | 停用后不参与过滤但保留在词库 |

**匹配模式说明**

| 模式 | 说明 | 示例 |
|------|------|------|
| 精确匹配 | 完全匹配才命中 | 词「违禁品」匹配「违禁品」，不匹配「违禁 品」 |
| 拼音匹配 | 拼音相同也命中 | 词「法轮」匹配「falun」 |
| 谐音匹配 | 常见谐音映射命中 | 系统内置谐音映射表 |
| 正则表达式 | 满足正则模式即命中 | `\d{17}[\dXx]` 匹配身份证号格式 |

**数据字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 敏感词 | 文本 | ✓ | 最长50字 |
| 匹配模式 | 枚举 | ✓ | 精确/拼音/谐音/正则 |
| 启用状态 | 布尔 | ✓ | 启用/停用 |
| 添加时间 | 时间戳 | 自动 | — |

> **接口联动**：敏感词库变更后，审核服务1分钟内同步生效。

### 3.3 内容管理

#### 3.3.1 知识领域管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 领域列表 | 表格展示全部知识领域，支持拖拽排序 | 排序影响小程序端展示顺序 |
| 新增领域 | 填写领域名称、图标、是否免费解锁 | 免费领域无需积分解锁，付费领域需配置解锁积分（30~60） |
| 编辑领域 | 修改名称、图标、解锁积分、免费状态 | 修改解锁积分不影响已解锁用户的访问权限 |
| 删除领域 | 删除领域及其下全部章节与卡片 | **高危操作**，需二次确认 + 输入领域名称验证；若有关联用户数据则软删除 |
| 排序调整 | 拖拽调整领域展示顺序 | 实时生效 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 领域名称 | 文本 | ✓ | 如"编程基础概念"，最长20字 |
| 领域图标 | 图标选择 | ✓ | 从预设图标库选择 |
| 排序序号 | 整数 | ✓ | 越小越靠前，自动生成 |
| 解锁所需积分 | 整数 | - | 免费领域不填，付费范围 30~60 |
| 是否免费 | 布尔 | ✓ | true=免费解锁，false=需积分解锁 |
| 状态 | 枚举 | ✓ | 上架 / 下架 |

#### 3.3.2 知识章节管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 章节列表 | 按知识领域分组展示章节，支持拖拽排序 | 排序影响小程序端展示顺序 |
| 新增章节 | 选择所属领域，填写章节名称 | 章节名称在同一领域下不可重复 |
| 编辑章节 | 修改名称、所属领域 | - |
| 删除章节 | 删除章节及其下全部卡片 | 需二次确认；若有关联卡片则提示数量 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 所属知识领域 | 下拉选择 | ✓ | 关联已有知识领域 |
| 章节名称 | 文本 | ✓ | 如"变量与数据类型"，最长30字 |
| 排序序号 | 整数 | ✓ | 越小越靠前 |
| 状态 | 枚举 | ✓ | 上架 / 下架 |

#### 3.3.3 知识卡片管理（核心）

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 卡片列表 | 表格展示，按章节/领域筛选，支持关键字搜索 | 支持下架卡片折叠显示 |
| 新增卡片 | 富文本编辑器填写卡片内容（或通过AI工作台生成） | 支持以下字段（详见数据字段表） |
| 编辑卡片 | 修改卡片任意字段 | 修改后不影响用户已有学习记录 |
| 删除卡片 | 软删除，标记为已删除状态 | 关联的学习记录保留 |
| 上架 / 下架 | 控制卡片在小程序端的可见性 | 下架后已学用户的记录保留但卡片不可见 |
| 卡片预览 | 侧边栏实时预览小程序端卡片展示效果 | 所见即所得 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 所属章节 | 下拉选择 | ✓ | 关联已有章节 |
| 卡片标题 | 文本 | ✓ | 知识点标题，如"什么是变量"，最长50字 |
| 核心概念 | 文本 | ✓ | 一句话概括，最长100字 |
| 详细说明 | 富文本 | ✓ | 2~3段详细解释，最长2000字 |
| 生活类比 | 文本 | - | 用生活场景类比帮助理解，最长500字 |
| 关键词标签 | 标签数组 | ✓ | 至少1个，最多5个标签 |
| 难度等级 | 枚举 | ✓ | 入门 / 基础 / 进阶 |
| 上架状态 | 布尔 | ✓ | 上架 / 下架 |
| 创建时间 | 时间戳 | 自动 | - |
| 更新时间 | 时间戳 | 自动 | - |

#### 3.3.4 题库管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 题目列表 | 表格展示，按关联卡片/领域筛选 | 显示关联卡片标题便于识别 |
| 新增题目 | 每张知识卡片可配置1道单选题 | 关联卡片、填写题干、4个选项、正确答案、解析 |
| 编辑题目 | 修改任意字段 | 修改后不影响用户历史答题记录 |
| 删除题目 | 删除题目 | 关联答题记录保留但题目标记为已删除 |
| 选项配置 | 4个选项，标记1个为正确答案 | 选项文本最长200字 |
| 解析编辑 | 富文本编辑题目解析 | 可用高亮标注关联的核心概念 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 关联卡片 | 下拉选择 | ✓ | 一对一关联知识卡片 |
| 题干 | 文本 | ✓ | 题目描述，最长500字 |

## 五、数据初始化方案

### 5.1 初始化原则

v1.0 的知识内容（领域、章节、卡片、题目）、成就徽章、运营配置的初始数据，采用 **AI 工作流辅助生成 + 人工审核** 的方式完成，不依赖手工逐条录入。

### 5.2 初始化流程

| 步骤 | 内容 | 执行方式 |
|:---:|------|---------|
| 1 | 知识领域与章节结构 | AI 根据 PRD §2.2.1 知识内容体系定义生成领域和章节的 JSON 种子数据，人工审核后执行数据库脚本导入 |
| 2 | 知识卡片内容 | AI 逐领域生成卡片内容（标题、核心概念、详细说明、生活类比、标签），输出 JSON，人工逐条审核后导入 |
| 3 | 题目 | AI 根据每张卡片内容生成 1 道单选题（题干、4选项、正确答案、解析），输出 JSON，人工审核后导入 |
| 4 | 成就徽章 | AI 根据积分体系设计建议徽章方案（名称、图标建议、所需积分、描述），人工确认后通过管理后台录入 |
| 5 | 运营默认配置 | AI 生成推荐配置参数（积分规则、复习默认、解锁消耗），人工确认后通过管理后台录入 |

### 5.3 AI 工作流规范

- 所有 AI 生成内容输出为结构化 JSON 格式，字段对齐 PRD 数据模型定义
- 每批生成内容附带「核验清单」，人工逐项勾选确认后方可导入
- AI 生成 → 人工审核 → 导入脚本执行，三步不可跳过
- 生成脚本和种子数据纳入版本管理（存放于 `backend/seeds/`）

### 5.4 后续内容维护

上线后的增量内容（新增卡片、新增题目、新增徽章等），运营者通过 Web 管理端直接操作，不再依赖 AI 工作流。AI 工作流仅用于初始化阶段的大批量数据灌入。

## 六、非功能需求

### 6.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面首屏加载 | ≤ 2s |
| 列表分页加载（100条） | ≤ 500ms |
| 卡片保存响应 | ≤ 1s |
| AI内容生成响应 | ≤ 10s（异步任务） |
| 数据看板图表渲染 | ≤ 2s |

### 6.2 安全要求

- 管理端登录需账号密码认证，密码加密存储（bcrypt）
- 登录态 Token 有效期 24 小时，过期需重新登录
- 敏感操作（删除领域/章节/卡片）需二次确认
- 所有操作记录操作日志，可追溯到人
- XSS 防护：富文本输入需做安全过滤
- AI审核内容需脱敏处理后发送至审核服务

### 6.3 兼容性

- 支持 Chrome 90+、Edge 90+、Firefox 88+
- 推荐分辨率 1920×1080，最低兼容 1366×768
- 不支持移动端浏览器（管理后台为 PC Web 端专用）

### 6.4 用户体验

- 所有列表支持分页、搜索、排序
- 表单操作有即时校验反馈
- 删除等危险操作有三层确认：弹窗确认 → 输入验证 → 结果反馈
- 操作成功后 Toast 提示，失败后展示错误原因
- AI生成内容支持流式展示（逐字段生成）

## 九、验收标准

### 9.1 总体验收条件

1. 管理员可通过 Web 后台完成知识领域 → 章节 → 卡片 → 题目的完整内容链路管理
2. 管理员可通过 AI 工作台输入主题，自动生成知识卡片与配套题目，审核后可采纳
3. 管理员可调整积分规则参数与广告配置，修改后小程序端实时生效
4. 用户笔记经由敏感词过滤 + AI审查 + 人工复核审核，不通过时仅用户自己可见
5. 管理员可上传 Banner 图片并配置跳转链接与有效期，小程序首页正确展示
6. 管理端支持日间/夜间模式切换，状态持久化
7. 数据看板能正确展示用户数、学习量、积分、广告等核心指标
8. 所有列表页面支持搜索、筛选、分页

## 十、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 内容管理操作失误导致小程序端内容异常 | 用户体验受损 | 删除操作多层确认；支持下架代替删除；配置变更支持回滚 |
| 积分规则调整不当导致经济体系失衡 | 用户激励失效 | 配置变更历史可回滚；参数变更需确认弹窗提示影响范围 |
| AI审核误判导致违规内容放行或正常内容被驳回 | 内容安全与用户体验风险 | AI审查+人工复核双重把关；驳回附带原因支持用户修改重提；敏感词库持续维护 |
| AI生成内容质量不稳定 | 人工审核负担增加 | 提供重新生成与版本选择；逐步优化提示词模板 |
| 广告配置不当导致用户体验下降 | 用户流失 | 开屏广告默认开启；提供一键开关控制；高级广告策略留至 v1.1+ |
| 管理后台密码泄露 | 内容安全风险 | 强密码策略；Token时效限制；操作日志审计 |
