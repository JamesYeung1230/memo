# CodeSail 小程序黑盒测试用例

> 测试对象：码上启航微信小程序（miniapp）
> 测试类型：手动黑盒测试
> 依据文档：[PRD.md](../miniapp/docs/PRD.md) + [交互设计.md](../miniapp/docs/交互设计.md)
> 覆盖范围：37 页面 + 17 组件，覆盖登录、首页、学习、笔记、积分、广告、个人中心

---

## 测试环境

| 配置项 | 说明 |
|--------|------|
| 小程序环境 | 微信开发者工具（模拟器）或真机预览 |
| 后端 API | `https://api.codesail.cn` (PROD) 或 VM 地址 |
| 测试账号 | 需准备一个微信测试账号（或 Mock 模式下使用任意 openid） |
| 管理员账号 | `admin` / `admin123`（用于 Web 端配合操作，如审核、配置） |
