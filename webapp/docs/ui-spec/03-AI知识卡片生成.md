## 三、批量主题输入区 Design Spec

### 输入行
- 每行：左侧 24px 灰色序号 `1.` `2.`，中间 input-text（宽度占满剩余空间），右侧 ✕ 删除按钮
- 高度：40px
- placeholder：`输入第 N 个主题关键词`
- 校验：不可为空（为空时边框红色）

### 动态增删
- 默认：1 个空输入行
- 点击 [+ 添加主题]：底部新增一行
- 上限 10 行：达到上限后 [+ 添加主题] 按钮变为禁用态（opacity 0.5, cursor not-allowed）
- 点击 ✕：删除该行，后续序号自动重排
- 至少保留 1 行：仅剩 1 行时 ✕ 按钮隐藏

### 章节选择
- 级联下拉选择：领域 → 章节
- 先选领域，再选章节
- 章节列表根据所选领域动态加载
- 两个下拉均必填

## 四、生成进度区 Design Spec

### 显示条件
- 点击 [开始生成] 后显示
- 生成完成后自动消失（或保留为摘要状态）

### Progress Bar
- 宽度：100%，高度 8px
- 颜色：品牌色 `#160C57`
- 百分比文字显示在右侧

### 主题状态列表
- 每个主题一行，左侧图标 + 主题名
- 图标：✓ 绿色（已完成）、◌ 蓝色旋转（生成中）、○ 灰色（等待中）、✕ 红色（失败）

| 状态 | 图标 | 文字色 |
|:-----|:-----|:-------|
| completed | ✓ `#10B981` | `#0F172A` |
| processing | ◌ 旋转动画 `#6366F1` | `#6366F1` |
| pending | ○ `#94A3B8` | `#94A3B8` |
| failed | ✕ `#EF4444` | `#EF4444` |

### 左侧版本切换区
- 宽度：240px
- 背景：浅灰 `#F8FAFC`
- 内边距：16px
- 每个版本条目：12px 时间 + status dot，hover 高亮
- 当前版本：左侧蓝色实线指示器 `#6366F1`

### 右侧编辑面板
- 每个字段独立可编辑
- **逐字段采纳开关**（Partial Adopt Toggle）：每个字段右侧的开关，默认全部开启
- 字数计数器：显示已输入/上限

## 七、交互状态汇总

| 状态 | 触发条件 | UI 表现 |
|:----|:---------|:--------|
| 空状态 | 无历史记录 | 空状态插画 "还没有AI生成的卡片，输入主题开始吧" |
| 生成中 | 点击开始生成 | 进度条 + 主题状态列表实时更新 |
| 生成失败 | 网络错误 | Toast "AI 生成失败，请重试" |
| 部分失败 | 部分主题失败 | 失败主题显示 ✕ 图标，成功主题可用 |
| 保存成功 | 采纳后 200 | Toast "卡片已保存至 {章节名}" |
| 采纳前 | 未选章节 | [采纳] 按钮禁用，提示 "请先选择所属章节" |

## 八、API 映射

| 页面操作 | API 端点 | 方法 |
|:---------|:---------|:----:|
| 开始生成卡片 | `POST /api/v1/ai/generate-cards` | body: `{topics: string[], chapter_id, mode: "sync"}` |
| 轮询异步结果 | `GET /api/v1/ai/generate-cards/{task_id}/result` | 轮询间隔 2s |
| 生成题目 | `POST /api/v1/ai/generate-questions/{card_id}` | body: `{mode: "sync"}` |
| 获取已有卡片 | `GET /api/v1/knowledge/cards?...` | 筛选用 |
| 获取领域/章节 | `GET /api/v1/knowledge/domains` + chapters | 级联下拉 |
| 采纳为正式卡片 | `POST /api/v1/knowledge/cards` | 保存到数据库 |
