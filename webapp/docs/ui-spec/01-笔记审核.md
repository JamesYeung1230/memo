## 三、统计栏 Design Spec

### 布局
- **容器**：白色背景 card，padding 16px，border-radius 8px，shadow-sm
- **4 个指标卡片**：flex 水平排列，间距 16px，等宽

### 每张指标卡片

```
┌───────────┐
│   12      │  ← 数字: 36px, Bold, #0F172A (Text Primary)
│  今日待审  │  ← 标签: 13px, Regular, #475569 (Text Secondary)
│           │
│  ▲ 15%    │  ← 趋势: 12px, success green (#10B981) / danger red (#EF4444)
└───────────┘
```

| 指标卡片 | 数据字段 | 趋势显示 |
|:---------|:---------|:---------|
| 今日待审 | `statistics.today_pending` | 与前日对比 |
| 今日已审 | `statistics.today_reviewed` | 与前日对比 |
| 7日通过率 | `statistics.weekly_approval_rate` + "%" 后缀 | 不显示趋势 |
| AI准确率 | `statistics.ai_accuracy` + "%" 后缀 | 不显示趋势 |

### 空数据态
- 数值显示为 `—`（短横线）
- 趋势箭头不显示

## 四、Tab 切换 Design Spec

| Tab | 标签文字 | 行为 |
|:----|:---------|:-----|
| 待审核 | `待审核 ● {count}` | 调用 `GET /api/v1/review/queue` |

## 五、待审核 Tab 表格 Design Spec

### 表格列定义

| 列 | 宽度 | 对齐 | 内容 | 数据类型 |
|:---|:----|:---:|:-----|:---------|
| 选择框 | 40px | 居中 | Checkbox | `review.id` |

### AI 审查结果区
- **背景色**：浅灰 `#F8FAFC`，padding 16px，border-radius 8px
- **Sensitive Word Highlight**：命中敏感词用黄色背景 `#FEF3C7` + 文字加粗高亮

### 审核时间线 (Audit Timeline)
- 每个阶段一个条目，左侧圆形状态点
- 已完成阶段：绿点 + 完成时间
- 当前阶段：黄点 + "进行中" / "待操作"
- 未到达阶段：灰点
- 条目间用垂直线连接

### 驳回输入
- 点击 [驳回] → 底部出现文本输入区
  - Textarea，最长200字，必填
  - 显示字数计数器 `0/200`
  - 确认按钮 "确认驳回" (btn-danger)
  - 取消按钮 "取消"

## 十、交互状态汇总

| 状态 | 触发条件 | UI 表现 |
|:----|:---------|:--------|
| 加载中 | 页面首次加载 | 骨架屏 |
| 无数据 | 待审核队列为空 | 空状态插画 + 引导文字 |
| 分页加载更多 | 翻页 | 表格数据更新，底部页码高亮 |
| 审核通过 | 点击通过按钮 | Toast "审核通过" 4s消失 |
| 审核驳回 | 点击驳回→填写原因→确认 | Toast "已驳回" 4s消失 |
| 批量操作 | 勾选多条 → 点击批量按钮 | 批量弹窗 → 确认 → Toast |
| 操作失败 | 网络错误 | Toast "操作失败，请重试" (error 红色) |
| Token 过期 | 操作后 401 返回 | 弹窗 "登录已过期" → 跳转登录页 |

## 十一、API 映射

| 页面操作 | API 端点 | 方法 |
|:---------|:---------|:----:|
| 获取待审核列表 | `GET /api/v1/review/queue?page=1&page_size=20` | 查询 |
| 获取审核记录 | `GET /api/v1/review/records?page=1&page_size=20&status=all` | 查询 |
| 获取审核统计 | `GET /api/v1/review/statistics` | 查询 |
| 获取审核详情 | `GET /api/v1/review/notes/{note_id}/detail` | 查询 |
| 审核通过 | `POST /api/v1/review/notes/{note_id}/approve` | 提交 |
| 审核驳回 | `POST /api/v1/review/notes/{note_id}/reject` | 提交 |
| 批量通过 | `POST /api/v1/review/batch-approve` | 提交 |
| 批量驳回 | `POST /api/v1/review/batch-reject` | 提交 |
