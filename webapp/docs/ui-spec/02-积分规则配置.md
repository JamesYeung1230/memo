## 三、表单行 Design Spec

### 单行布局

```
Label (14px Regular, #475569, 左对齐, 宽度180px)
        输入框 (input-number, 宽度 120px, 右对齐文本)
              范围提示 (12px, #94A3B8)
                错误提示 (12px, #EF4444, 只在校验失败时显示)
```

### 输入框规格
- **类型**：`<input type="number">`
- **宽度**：120px
- **高度**：40px
- **对齐**：文字右对齐（方便比较数值大小）
- **边距**：label 与 input 间距 16px
- **步进按钮**：右侧上下箭头，点击+1/-1

### 校验规则
- 超出范围：输入框边框变红 `#EF4444`，底部显示 "范围: 1~5"
- 非数字输入：提示 "请输入有效数字"
- 保存时全部校验，任一字段非法则阻止保存

## 四、分组卡片 Design Spec

### 卡片容器
- 背景：白色 `#FFFFFF`
- 内边距：padding 24px
- 圆角：border-radius 8px
- 阴影：shadow-sm
- 底部外边距：16px（卡片间间距）

### 组标题
- 标题文字：18px Semibold, `#0F172A`
- 标题下方：2px 高的分割线 `#E2E8F0`
- 标题距分割线：8px
- 分割线距第一个表单行：16px

## 五、底部操作栏 Design Spec

| 按钮 | 样式 | 位置 |
|:-----|:-----|:-----|
| 重置为默认值 | btn-ghost, 左侧 | 左侧浮动 |
| 保存配置 | btn-primary (bg #160C57), 右侧 | 右侧浮动 |

- 容器：白色背景，顶部 1px border `#E2E8F0`
- padding: 16px 24px
- 固定在页面底部（页面滚动时始终可见），或跟随页面底部

## 六、配置变更历史区 Design Spec

### 收起态
```
配置变更历史 (H3)                        [展开 ▾]
```
- 点击展开后变为 `[收起 ▴]`

### 展开态
- 表格展示，无分页（历史版本通常不超过20条）
- 列定义：

| 列 | 宽度 | 内容 | 来源 |
|:---|:-----|:-----|:-----|
| 版本 | 80px | `v{version}` | `config.version` |
| 更新时间 | 180px | `YYYY-MM-DD HH:mm` | `updated_at` |
| 更新人 | 120px | 管理员用户名 | `updated_by` |
| 操作 | 160px | [回滚到此版本] 或 (当前版本) | — |

- 当前版本行：操作列显示灰色标签 "(当前版本)"，不可点击
- 历史版本行：[回滚到此版本] 按钮，btn-ghost sm，点击后弹出 confirm："确认回滚到 v{N}？当前配置将被覆盖"

### 空数据态
```
暂无配置变更历史
```

## 七、交互状态汇总

| 状态 | 触发条件 | UI 表现 |
|:----|:---------|:--------|
| 加载中 | 页面首次加载 | 骨架屏（5个卡片区域各5行骨架） |
| 加载失败 | API 错误 | Toast "加载配置失败" + 重试按钮 |
| 保存成功 | 保存后 200 | Toast "保存成功，已实时生效" |
| 保存失败 | 网络/校验错误 | Toast "保存失败" + 红色 |
| 校验失败 | 数值超出范围 | 输入框红色边框 + 范围提示 |
| 回滚确认 | 点击回滚按钮 | 弹窗确认 |
| 回滚成功 | 回滚后 200 | Toast "已回滚到 v{N}" |

## 八、API 映射

| 页面操作 | API 端点 | 方法 |
|:---------|:---------|:----:|
| 获取积分规则 | `GET /api/v1/admin/points-rules` | `{points_rules: {...}, checkin_milestones: {...}}` |
| 保存积分规则 | `PUT /api/v1/admin/points-rules` | body: `{points_rules: {...}}` |
| 获取变更历史 | `GET /api/v1/admin/points-rules/history` | 返回当前版本信息 + history_entries[] |
| 重置为默认值 | 前端填入种子默认值后调 PUT | — |

### 请求/响应示例

**GET 响应结构**:
```json
{
  "data": {
    "points_rules": {
      "learn_card": 1,
      "daily_learn_card_limit": 10,
      "daily_challenge": 15,
      "daily_challenge_limit": 15,
      "create_note": 5,
      "daily_create_note_limit": 15,
      "ad_watch": 10,
      "daily_ad_watch_limit": 100
    },
    "checkin_milestones": {
      "3": 15,
      "7": 30,
      "14": 60
    }
  }
}
```

**PUT 请求体**:
```json
{
  "points_rules": { "...": "..." }
}
```
