## 三、表格列

| 列 | 宽度 | 内容 |
|:---|:-----|:------|
| 选择框 | 40px | Checkbox (支持批量删除) |
| 敏感词 | 25% | 截断30字，`word` 字段 |
| 匹配模式 | 15% | Badge: 精确=蓝 `#DBEAFE` / 拼音=紫 `#EDE9FE` / 谐音=橙 `#FED7AA` / 正则=灰 `#F1F5F9` |
| 状态 | 12% | Status Badge: 启用/停用 |
| 添加时间 | 18% | `created_at` |
| 操作 | 20% | [编辑] [启用/停用] [删除] |

## 五、API 映射

| 操作 | API |
|:----|:-----|
| 列表 | `GET /api/v1/sensitive-words?page=&page_size=&keyword=` |
| 新增 | `POST /api/v1/sensitive-words` body: `{word, match_mode, enabled}` |
| 编辑 | `PUT /api/v1/sensitive-words/{id}` |
| 删除 | `DELETE /api/v1/sensitive-words/{id}` |
| 批量删除 | `POST /api/v1/sensitive-words/batch-delete` body: `{ids: []}` |
| 启用/停用 | `PUT /api/v1/sensitive-words/{id}/toggle` body: `{enabled: bool}` |


### 内容数据 (/analytics/content)
- 3 个图表卡片，2列布局（左宽右窄，或上2下1）
- 领域学习热度：水平条形图
- 卡片学习排行 TOP10：横向柱状图
- 题目正确率：柱状图（按领域分组）

### 用户数据 (/analytics/users)  
- 用户增长趋势：双折线图（累计 + 新增）
- 活跃度分布：环形图（高/中/低/沉默）
- 学习行为漏斗：漏斗图（5步转化）

### 积分与广告数据 (/analytics/revenue)
- 积分发放/消耗趋势：双折线图
- 广告展示/点击：柱状图
- 积分获取占比：环形图

### 图表通用规格
- 图表库：使用 Recharts / ECharts
- 每个图表卡片：白色背景，padding 16px，8px radius，shadow-sm
- 标题：14px Semibold
- 宽高比：2:1（宽800px，高400px）
- 空数据：图表区显示 "暂无数据"
- 加载中：Skeleton 占位
