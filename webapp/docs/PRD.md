## 一、产品概述

### 1.1 产品名称

**码上启航 — 运营管理后台**（CodeSail Admin）

### 1.2 产品定位

一款面向「码上启航」微信小程序运营人员的 **Web 端内容管理与运营配置后台**，提供知识内容的全生命周期管理、运营策略的灵活配置以及核心数据指标的实时监控能力。

### 1.3 目标用户

| 用户角色 | 特征描述 | 核心诉求 |
|---------|---------|---------|
| **内容运营** | 负责知识卡片、题库内容的创建与维护 | 快速录入/编辑知识内容、批量管理卡片与题目、编排知识结构 |
| **活动运营** | 负责积分策略、Banner推广等运营配置 | 灵活调整积分规则、配置首页Banner与主题、查看运营效果数据 |
| **管理员** | 统筹管理后台账号与系统配置 | 管理运营人员账号与权限、查看全局数据看板 |

### 1.4 与小程序的关系

```
┌─────────────────────────────┐      ┌─────────────────────────────┐
│   码上启航 微信小程序         │      │   码上启航 Web 管理端          │
│   (C端 — 学习用户)           │◄─────│   (B端 — 运营人员)            │
│                              │ 数据  │                              │
│  · 浏览知识卡片              │ 同步  │  · 知识内容管理(增删改查)      │
│  · 答题练习                  │      │  · 题库管理与维护              │
│  · 记忆强化复习              │      │  · 积分规则 / 解锁配置         │
│  · 积分获取与消耗            │      │  · Banner / 主题色运营         │
│  · 观看广告                  │      │  · 数据看板与统计分析           │
│                              │      │  · 管理员账号与权限             │
└─────────────────────────────┘      └─────────────────────────────┘
```

### 1.5 产品核心价值

1. **内容管理提效**：结构化编辑器 + 批量操作，运营人员无需技术背景即可维护知识内容
2. **运营策略灵活**：积分规则、解锁消耗等核心参数可在后台直接调整，无需发版
3. **数据驱动决策**：学习数据、积分数据、用户数据可视化呈现，指导运营方向

## 三、功能详细需求

### 3.1 登录与权限

#### 3.1.1 登录方式

| 功能点 | 描述 |
|-------|------|

#### 3.1.2 角色与权限矩阵

| 权限点 | 管理员 | 内容运营 | 活动运营 |

| 题库管理 | ✓ | ✓ | ✗ |
| 积分规则配置 | ✓ | ✗ | ✓ |
| 解锁消耗配置 | ✓ | ✗ | ✓ |
| Banner / 主题色配置 | ✓ | ✗ | ✓ |
| 数据看板 | ✓ | ✓(仅内容) | ✓(仅运营) |
| 用户管理 | ✓ | ✗ | ✗ |
| 管理员账号管理 | ✓ | ✗ | ✗ |

### 3.2 内容管理

#### 3.2.1 知识领域管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 领域列表 | 表格展示全部知识领域，支持拖拽排序 | 排序影响小程序端展示顺序 |
| 新增领域 | 填写领域名称、图标、是否免费解锁 | 免费领域无需积分解锁，付费领域需配置解锁积分（30~60） |
| 编辑领域 | 修改名称、图标、解锁积分、免费状态 | 修改解锁积分不影响已解锁用户的访问权限 |
| 删除领域 | 删除领域及其下全部章节与卡片 | **高危操作**，需二次确认 + 输入领域名称验证；若有关联用户数据则软删除 |
| 排序调整 | 拖拽调整领域展示顺序 | 实时生效 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 领域名称 | 文本 | ✓ | 如"编程基础概念"，最长20字 |
| 领域图标 | 图标选择 | ✓ | 从预设图标库选择 |
| 排序序号 | 整数 | ✓ | 越小越靠前，自动生成 |
| 解锁所需积分 | 整数 | - | 免费领域不填，付费范围 30~60 |
| 是否免费 | 布尔 | ✓ | true=免费解锁，false=需积分解锁 |
| 状态 | 枚举 | ✓ | 上架 / 下架 |

#### 3.2.2 知识章节管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 章节列表 | 按知识领域分组展示章节，支持拖拽排序 | 排序影响小程序端展示顺序 |
| 新增章节 | 选择所属领域，填写章节名称 | 章节名称在同一领域下不可重复 |
| 编辑章节 | 修改名称、所属领域 | - |
| 删除章节 | 删除章节及其下全部卡片 | 需二次确认；若有关联卡片则提示数量 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 所属知识领域 | 下拉选择 | ✓ | 关联已有知识领域 |
| 章节名称 | 文本 | ✓ | 如"变量与数据类型"，最长30字 |
| 排序序号 | 整数 | ✓ | 越小越靠前 |
| 状态 | 枚举 | ✓ | 上架 / 下架 |

#### 3.2.3 知识卡片管理（核心）

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 卡片列表 | 表格展示，按章节/领域筛选，支持关键字搜索 | 支持下架卡片折叠显示 |
| 新增卡片 | 富文本编辑器填写卡片内容 | 支持以下字段（详见数据字段表） |
| 编辑卡片 | 修改卡片任意字段 | 修改后不影响用户已有学习记录 |
| 删除卡片 | 软删除，标记为已删除状态 | 关联的学习记录保留 |
| 上架 / 下架 | 控制卡片在小程序端的可见性 | 下架后已学用户的记录保留但卡片不可见 |
| 批量导入 | 支持 Excel / JSON 格式批量导入卡片 | 模板下载 → 填写 → 上传 → 预览确认 → 导入；单次上限 200 张 |
| 批量导出 | 导出选中卡片为 Excel | 用于备份或线下编辑 |
| 卡片预览 | 侧边栏实时预览小程序端卡片展示效果 | 所见即所得 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 所属章节 | 下拉选择 | ✓ | 关联已有章节 |
| 卡片标题 | 文本 | ✓ | 知识点标题，如"什么是变量"，最长50字 |
| 核心概念 | 文本 | ✓ | 一句话概括，最长100字 |
| 详细说明 | 富文本 | ✓ | 2~3段详细解释，最长2000字 |
| 生活类比 | 文本 | - | 用生活场景类比帮助理解，最长500字 |
| 关键词标签 | 标签数组 | ✓ | 至少1个，最多5个标签 |
| 难度等级 | 枚举 | ✓ | 入门 / 基础 / 进阶 |
| 上架状态 | 布尔 | ✓ | 上架 / 下架 |
| 创建时间 | 时间戳 | 自动 | - |
| 更新时间 | 时间戳 | 自动 | - |

#### 3.2.4 题库管理

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| 题目列表 | 表格展示，按关联卡片/领域筛选 | 显示关联卡片标题便于识别 |
| 新增题目 | 每张知识卡片可配置1道单选题 | 关联卡片、填写题干、4个选项、正确答案、解析 |
| 编辑题目 | 修改任意字段 | 修改后不影响用户历史答题记录 |
| 删除题目 | 删除题目 | 关联答题记录保留但题目标记为已删除 |
| 选项配置 | 4个选项，标记1个为正确答案 | 选项文本最长200字 |
| 解析编辑 | 富文本编辑题目解析 | 可用高亮标注关联的核心概念 |

**数据字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 关联卡片 | 下拉选择 | ✓ | 一对一关联知识卡片 |
| 题干 | 文本 | ✓ | 题目描述，最长500字 |
| 选项A~D | 文本×4 | ✓ | 每题必须4个选项 |
| 正确答案 | 单选项 | ✓ | 标记 A/B/C/D 之一 |
| 解析说明 | 富文本 | ✓ | 答案解释，最长1000字 |
| 题目状态 | 枚举 | ✓ | 启用 / 停用 |

### 3.3 运营配置

#### 3.3.1 积分规则配置

对应小程序 PRD §2.4.1 积分体系，Web 管理端提供以下参数的可视化配置：

| 配置项 | 默认值 | 可配范围 | 说明 |
|-------|:----:|:------:|------|
| 学习1张卡片(点「懂了」)积分 | 1 | 1~5 | 单次学习积分 |
| 学习卡片每日上限 | 10 | 5~30 | 防止刷分 |
| 每日挑战(全对)积分 | 15 | 10~30 | 挑战完成奖励 |
| 每日挑战每日上限 | 15 | 10~30 | - |
| 连续打卡第3天积分 | 15 | 10~30 | 里程碑奖励 |
| 连续打卡第7天积分 | 30 | 20~60 | 周里程碑 |
| 连续打卡第14天积分 | 60 | 40~100 | 双周里程碑 |
| 创建笔记(≥20字)积分 | 5 | 1~10 | 有效笔记奖励 |
| 创建笔记每日上限 | 15 | 5~30 | - |
| 观看激励广告积分 | 10 | 5~20 | 广告积分 |
| 观看激励广告每日上限 | 100 | 50~200 | - |

**交互说明**：
- 以表单形式展示当前配置值，运营人员修改后点击保存即可
- 修改后实时生效于小程序端
- 保留配置变更历史记录，支持回滚到历史版本
- 配置值有范围校验，超出范围不可保存

#### 3.3.2 解锁消耗配置

| 配置项 | 默认值 | 可配范围 | 说明 |
|-------|:----:|:------:|------|
| K04 解锁积分 | 40 | 30~60 | 计算机网络基础 |
| K05 解锁积分 | 40 | 30~60 | 操作系统基础 |
| K06 解锁积分 | 50 | 30~60 | AI编程实践技巧 |
| K07 解锁积分 | 60 | 30~60 | AI编程与传统编程 |
| 高级知识卡片解锁 | 20 | 10~40 | 部分进阶知识点 |

**交互说明**：
- 列表形式展示各知识领域的当前解锁积分
- 免费领域（K01~K03）不可配置解锁积
- 保存后实时生效

#### 3.3.3 首页运营配置

| 功能点 | 描述 | 业务规则 |
|-------|------|---------|
| **Banner 管理** | 首页轮播 Banner 的上传、排序、下架 | 支持图片上传（≤2MB，推荐 750×400px）；可配置跳转链接（小程序内页面路径）；最多 5 张轮播 |
| **主题色配置** | 小程序全局主题色设置 | 提供色板选择器 + 预设推荐色；实时预览效果；品牌默认色 `#160C57` 深紫色 |

#### 3.3.4 广告策略配置（v1.1+）

> v1.0 暂不包含，后续迭代补充。包括激励广告展示频率、开屏广告开关、广告位管理等。

### 3.4 数据看板

#### 3.4.1 核心指标概览

| 指标 | 展示形式 | 说明 |
|------|---------|------|
| 累计注册用户数 | 数字卡片 | 小程序累计授权用户数 |
| 今日活跃用户(DAU) | 数字卡片 + 环比变化 | 当日有学习行为的用户数 |
| 今日学习卡片数 | 数字卡片 | 当日用户点击「懂了」的卡片总数 |

| 今日积分发放量 | 数字卡片 | 当日系统发放积分总量 |
| 7日留存率 | 数字卡片 + 趋势箭头 | 7天前新增用户中第7天仍有学习行为的比例 |

**交互说明**：
- 默认展示「今日」数据，支持切换「昨日」「近7天」「近30天」
- 每个指标卡片显示环比变化（↑ 绿色 / ↓ 红色）

#### 3.4.2 内容数据

| 图表 | 类型 | 说明 |
|------|------|------|

| 各领域答题正确率 | 雷达图 / 柱状图 | 展示各领域用户平均正确率 |
| 内容总量统计 | 汇总数字 | 知识领域数 / 章节数 / 卡片数 / 题目数 |

#### 3.4.3 用户数据

| 图表 | 类型 | 说明 |

| 用户活跃度分布 | 饼图 | 高活/中活/低活/沉默用户占比 |
| 学习行为漏斗 | 漏斗图 | 打开小程序 → 浏览卡片 → 点「懂了」→ 完成答题 → 创建笔记 |

- 数据导出：支持导出为 Excel
- 自动刷新：看板每 5 分钟自动刷新（可手动刷新）

## 五、非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面首屏加载 | ≤ 2s |
| 列表分页加载（100条） | ≤ 500ms |
| 卡片保存响应 | ≤ 1s |
| 批量导入（200条） | ≤ 5s（含校验） |
| 数据看板图表渲染 | ≤ 2s |

### 5.2 安全要求

- 管理端登录需账号密码认证，密码加密存储（bcrypt）
- 登录态 Token 有效期 24 小时，过期需重新登录
- 敏感操作（删除领域/章节/卡片）需二次确认
- 所有操作记录操作日志，可追溯到人
- XSS 防护：富文本输入需做安全过滤

### 5.3 兼容性

- 支持 Chrome 90+、Edge 90+、Firefox 88+
- 推荐分辨率 1920×1080，最低兼容 1366×768
- 不支持移动端浏览器（管理后台为 PC Web 端专用）

### 5.4 用户体验

- 所有列表支持分页、搜索、排序
- 表单操作有即时校验反馈
- 删除等危险操作有三层确认：弹窗确认 → 输入验证 → 结果反馈
- 操作成功后 Toast 提示，失败后展示错误原因
- 长时间操作（批量导入）展示进度条

## 八、验收标准

### 8.1 总体验收条件

1. 运营人员可通过 Web 后台完成知识领域 → 章节 → 卡片 → 题目的完整内容链路管理
2. 运营人员可调整积分规则参数，修改后小程序端实时生效
3. 运营人员可上传 Banner 图片并配置跳转链接，小程序首页正确展示
4. 数据看板能正确展示用户数、学习量、积分等核心指标
5. 管理端角色权限控制正确：内容运营无法修改积分配置，活动运营无法编辑内容
6. 所有列表页面支持搜索、筛选、分页
7. 批量导入功能可正确解析 Excel/JSON 并校验数据格式

### 8.2 各模块验收要点

| 模块 | 核心验收点 |
|------|-----------|
| 登录与权限 | 三角色登录后菜单可见性正确；无权限接口返回403 |
| 知识领域/章节 | CRUD闭环完整；排序拖拽生效；删除领域级联提示准确 |
| 知识卡片 | 富文本编辑正常保存；上架/下架状态切换生效；批量导入校验准确、错误行有明确提示 |
| 题库管理 | 选项必须4个；正确答案唯一；题目与卡片关联正确 |
| 积分配置 | 修改参数后保存成功；超出范围有校验拦截；变更历史可查看 |
| Banner管理 | 图片上传成功；排序调整生效；跳转链接配置正确 |
| 数据看板 | 指标数值与后端数据一致；时间范围切换数据正确更新；图表渲染无异常 |
| 操作日志 | 关键操作均有记录；可按操作人/时间筛选 |

## 九、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 内容管理操作失误导致小程序端内容异常 | 用户体验受损 | 删除操作多层确认；支持下架代替删除；配置变更支持回滚 |
| 积分规则调整不当导致经济体系失衡 | 用户激励失效 | 配置变更历史可回滚；参数变更需确认弹窗提示影响范围 |
| 批量导入数据格式错误 | 导入失败或数据异常 | 导入前预览校验；错误行明确标注；支持回滚 |
| 管理后台权限泄露 | 内容安全风险 | 强密码策略；Token时效限制；操作日志审计 |
