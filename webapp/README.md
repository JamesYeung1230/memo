# 码上启航 — Web 端管理后台（CodeSail Admin）

## 项目简介

本目录是「码上启航」平台的 **Web 端运营管理后台**，面向内容运营、活动运营和管理员，提供知识内容的生命周期管理、运营策略灵活配置以及核心数据指标的实时监控能力。

「码上启航」是一款面向非专业编程用户的 AI 编程学习小程序，通过碎片化、轻量化的知识卡片与刷题练习，帮助用户建立计算机基础认知，从而更高效地驾驭 AI 工具完成软件开发任务。

## 核心功能模块

| 模块 | 说明 |
|------|------|
| 内容管理 | 知识领域 → 章节 → 卡片（三级结构）的增删改查与批量导入 |
| 题库管理 | 单选题的创建、编辑、答案配置与解析维护 |
| 运营配置 | 积分规则参数调整、解锁消耗配置、Banner 轮播与主题色管理 |
| 数据看板 | 核心指标、内容数据、用户数据、积分广告数据的可视化展示 |
| 用户管理 | 小程序用户列表查看与学习详情 |
| 系统管理 | 管理员账号管理与操作日志审计 |
