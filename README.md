# 码上启航 (CodeSail)

> 📱 一款面向非专业编程用户的 AI 编程知识学习平台

「码上启航」通过**知识卡片 + 选择题测验 + 间隔重复记忆强化**三大认知科学方法，帮助 AI 编程学习者建立计算机基础认知和软件开发基本概念，使其更高效地驾驭 AI 工具完成软件开发任务。

**核心闭环**：知识卡片（输入） → 刷题 + 记忆强化（巩固） → AI 编程实践（输出），积分体系贯穿全程。

## 产品功能全景

### 微信小程序 (C端)

| 模块 | 核心功能 |
|------|---------|
| **知识学习** | 7 大知识领域（K01~K07，三级结构：领域→章节→知识点）；卡片浏览 + 单选题刷题；错题本自动收集 |
| **记忆强化** | 基于艾宾浩斯遗忘曲线的间隔复习、错题再练、笔记回顾、遗忘预警；用户可自定义复习计划 |
| **笔记管理** | 自由笔记 + 关联笔记；三级审核流程（敏感词→AI审查→人工复核）；审核通过后支持分享 |
| **积分体系** | 学习打卡/每日挑战/创建笔记/观看激励广告获取积分；积分解锁高级知识领域和成就徽章 |
| **首页个性化** | Banner 轮播（运营推送）、主题色管理端动态下发、首页模块显隐与拖拽排序 |

### Web 管理后台 (B端)

| 模块 | 核心功能 |
|------|---------|
| **AI 内容工作台** | AI 知识卡片生成、AI 题目生成、笔记人工复核、敏感词库管理（4 种匹配模式） |
| **内容管理** | 知识领域/章节/卡片/题目的增删改查、排序、上下架 |
| **运营配置** | 积分规则、解锁消耗、Banner 管理、成就徽章、广告开关、复习默认配置 |
| **数据看板** | 核心指标、内容数据、用户数据、积分与广告数据可视化 |
| **系统管理** | 管理员密码修改、操作日志（删除类高危操作追溯） |

### 后端微服务 (API 层)

| 服务 | 端口 | 职责 |
|------|:----:|------|
| **Auth Service** | 8001 | 管理员登录、微信登录、JWT 签发与刷新 |
| **Knowledge Service** | 8002 | 知识内容 CRUD、AI 内容生成（DeepSeek）、内容审核 |
| **Core Service** | 8000 | API 网关 + 业务编排、学习记录、记忆强化、积分体系、笔记管理、运营配置、数据看板 |
